# MURMUR — 군체의 생존

머리 하나를 조종하고, 각 개체가 주변 이웃에 반응하며 움직이는 군체를 키우는 싱글플레이 브라우저 생존 게임 프로토타입입니다. 외부 라이브러리·이미지·폰트·회원가입 없이 동작하며, 닉네임과 생존 랭킹은 작은 서버에 저장합니다.

## 실행

이 폴더에서 아래 명령을 실행한 뒤 <http://127.0.0.1:4173>을 여세요. Node.js 24 이상이 필요하며 추가 패키지 설치는 없습니다.

```sh
node server/local.mjs
```

이 서버는 게임 파일과 랭킹 API를 제공합니다. 게임 로직과 적 AI는 모두 브라우저에서 실행하며 실시간 멀티플레이 통신은 없습니다. `index.html`을 직접 여는 방식은 브라우저의 모듈 보안 정책 때문에 지원하지 않습니다. 기존 Python 정적 서버만 실행하면 랭킹 API가 없으므로 새 서버를 사용하세요. `PORT`로 포트, `MURMUR_DB`로 데이터베이스 파일 위치를 지정할 수 있습니다.

## 닉네임과 랭킹

- 첫 화면에서 1~16자 닉네임을 입력하고 Enter 또는 **플레이**를 누릅니다. `닉네임#고유번호` 형태로 표시하며, 같은 이름을 입력해도 서로 다른 플레이어입니다.
- 플레이어 식별자와 비밀 토큰은 이 브라우저에 저장합니다. 닉네임을 바꾸어도 고유번호와 기록은 유지됩니다. 다른 기기·브라우저를 쓰거나 브라우저 데이터를 삭제하면 새 플레이어가 됩니다. 계정 복구나 기기 간 로그인 기능은 없습니다.
- 게임 종료 시 자동 등록합니다. 기록 도전·긴 생존·빠른 플레이를 각각 구분하고, 연습과 중도 포기는 등록하지 않습니다. 생존 시간을 0.1초 단위로 비교하며 동점은 최대 군체, 처치 수, 먼저 달성한 시각, 플레이어 식별자 순으로 정렬합니다.
- 플레이어당 모드별 최고 기록 한 줄을 표시합니다. 상위 10명과, 10위 밖일 때 내 순위를 확인할 수 있습니다. 이전의 이름 없는 브라우저 최고 기록은 자동으로 랭킹에 옮기지 않습니다.
- 연결 실패 시 완주 기록을 브라우저에 대기 저장하고 최대 30초 간격으로 재시도합니다. 새로고침·다음 플레이·랭킹 새로고침 때도 재전송합니다. 같은 경기 번호의 중복 요청은 최초 기록 한 번만 반영합니다. 브라우저 저장이 차단되면 이번 방문 동안만 대기 기록을 보관합니다.
- 서버 데이터는 `.data/ranking.sqlite`에 영구 저장하며, 같은 서버에 접속한 브라우저끼리 공유합니다. DB와 서버 소스는 웹으로 제공하지 않습니다. 다른 플레이어의 기록을 덮어쓰지 못하도록 서버는 토큰의 해시를 검증합니다. 랭킹 응답에 토큰을 포함하지 않습니다.

[Sites 주소](https://murmur-flock-survivor.skaparty.chatgpt.site)에 배포하도록 연결되어 있습니다. `server/worker.mjs`는 동일한 API를 D1의 `DB` 바인딩과 정적 파일의 `ASSETS` 바인딩으로 실행합니다. `.openai/hosting.json`은 사이트 연결과 D1 설정을 보관합니다. `npm run build`는 Worker와 게임 정적 파일을 `dist`에 패키징합니다. 로컬 `.data`의 기록은 업로드하지 않으며, Sites 랭킹은 별도 데이터베이스를 사용합니다. 배포 후 게임과 랭킹의 실제 동작 검증은 사용자가 진행합니다.

이 랭킹은 시제품용입니다. 서버에서 입력 범위·모드·중복 요청·플레이어 소유권을 검증하지만, 생존 시간 등 결과 자체는 브라우저가 전송합니다. 경쟁용 공개 랭킹의 점수 위변조 방지를 위해서는 서버 시뮬레이션이나 입력 재생 검증이 추가로 필요합니다.

## 조작

| 입력 | 행동 |
| --- | --- |
| 마우스 이동 | 머리가 포인터 방향으로 회전 |
| WASD / 방향키 | 해당 방향으로 회전, 마우스 입력보다 우선 |
| Space / 마우스 왼쪽 버튼 유지 | 에너지를 소모해 가속. 머리가 먼저 치고 나가고, 이웃을 통해 가속이 전달됨 |
| Shift / 마우스 오른쪽 버튼 유지 | 감속·결집. 느리게 선회하면서 무리의 폭을 줄임 |
| 화면의 결집 버튼 | 결집 모드 켜기·끄기. 키보드 없이도 사용 가능 |
| 터치 드래그 | 손가락 방향으로 이동 |
| 두 손가락 터치 | 가속 |
| Esc / P | 일시정지·재개 |
| 진화하기 버튼 / E 위치 키 | 진화 에너지가 충분할 때 진화 시작. 한글 입력 상태에서도 같은 키를 누를 수 있으며, 능력을 고르는 동안 시간이 멈춤 |
| 1 / 2 / 3 | 진화 선택 |
| 사망 화면에서 R / 재도전 버튼 | 같은 모드로 즉시 다시 시작 |

기본 **기록 도전**은 시간 제한 없이 생존 기록을 늘리는 모드입니다. 첫 진화를 일찍 경험하고, 짧은 판을 반복하며 군체 운영을 익힙니다. **다른 방식으로 시작**에는 기존 **긴 생존(30분)**, **빠른 플레이(3분)**와 연습 모드를 남겨두었습니다. **조작 연습**에서는 적·제한시간 없이 48마리와 자유 비행할 수 있습니다.

**다른 방식으로 시작 → 꼬리 데려오기 연습**에서는 내 12마리와 적 64마리로 같은 장면을 반복할 수 있습니다. 결집이 켜진 채 적 꼬리 옆에서 시작합니다. 방향을 바꾸지 않고 오른쪽으로 함께 날면 약 3초 뒤 꼬리 끝 1마리가 합류합니다. 연습 상대만 직진하며, 이동·충돌·영입 판정은 일반 게임과 같습니다. 성공 문구와 다시 해보기 버튼으로 결과를 확인할 수 있습니다.

화면에는 시간·무리 수·가속 에너지·진화 진행도를 표시하고, 동요·합류 숫자는 해당 개체가 있을 때만 나타납니다. 처치·흡수·누적 이탈과 선택한 모든 능력은 **일시정지 → 이번 무리의 기록과 능력**에서 확인합니다. 연습에서는 목표 시간과 진화 진행도를 표시하지 않습니다. 게임 화면은 모바일 세로형 프레임을 기준으로 고정해 데스크톱과 모바일에서 같은 배치와 시야를 사용하며, 데스크톱의 남는 좌우 공간은 배경으로 남깁니다.

먹이를 흡수하면 **진화 에너지**가 쌓입니다. 필요한 양을 모으면 화면 아래 **진화하기** 버튼이 초록색으로 켜집니다. 준비된 동안에도 비행은 계속되며, 버튼이나 키보드의 E 위치 키를 눌러야 진화 선택창이 열립니다. 키보드가 한글 입력 상태여도 같은 물리 키로 작동합니다. 모아 둔 에너지는 사라지지 않고 계속 쌓입니다. 한 번 누를 때 한 단계만 진화하며, 남은 에너지로 다시 진화할 수 있어도 다음 버튼 입력을 기다립니다.

**도움말**에서 조작과 생존 규칙을 확인할 수 있습니다. 플레이 중 열면 시간이 멈추고, 닫으면 이어집니다. 일시정지 화면에서 연 도움말은 닫아도 일시정지를 유지합니다. 작은 화면에서는 **일시정지 → 조작과 생존 규칙**을 이용하세요. 접힌 메뉴와 대화상자는 Tab·Shift+Tab·Enter·Space로 조작할 수 있고, Esc로 도움말을 닫거나 일시정지를 해제합니다.

머리는 계속 전진하며, 선회 속도가 서서히 쌓이고 줄어드는 관성이 있습니다. 반대 방향을 입력해도 기존 선회를 먼저 줄인 뒤 돌아섭니다. 입력 방향만 뒤로 돌린다고 급감속하지 않으며 실제 선회에 따른 감속은 작게 적용됩니다. 가속할수록 더 큰 원을 그리고, 결집하면 감속을 통해 좁게 돕니다. 결집 자체가 선회 속도 상한을 올리지는 않습니다. 결집과 가속을 동시에 입력하면 결집이 우선합니다.

기본 최대 선회 속도는 초당 약 69도이고, Cohesion 한 단계당 10%씩 증가해 최대 약 103도까지 올라갑니다. 최대 진화에서도 각가속도와 속도에 따른 선회 제한이 유지됩니다. 정면에서 뒤쪽 방향을 계속 입력할 때 기본 유턴은 약 3.2초, Cohesion 5단계에서는 약 2.4초가 걸립니다. 테두리의 흐름도 속도와 회전 반경을 미리 고려하며 같은 선회 한계를 따릅니다.

적의 **머리가 내 군체 개체에 닿으면 적이 사망**하고, **내 머리가 적 군체 개체에 닿으면 게임이 끝납니다**. **대장끼리 부딪히면 규모·속도와 관계없이 양쪽이 동시에 사망**합니다. 이 충돌에는 승자가 없으며 플레이어 처치 수가 늘어나지 않습니다. 적끼리도 같은 규칙을 적용하고, 죽은 적은 기존처럼 전투 잔해를 남깁니다. 같은 순간 몸통에도 닿았다면 대장 간 충돌을 우선합니다. 자신의 군체와 몸통끼리의 접촉은 안전합니다. 테두리는 즉사 벽이 아니라 머리를 안쪽으로 돌리는 흐름입니다. 시작과 적 등장에는 짧은 충돌 유예가 있습니다.

## 한 판의 흐름

플레이어 대장은 진화 단계마다 처음 지름의 10%씩 커집니다. 1단계 1배 → 11단계 2배 → 21단계 3배 → 31단계 최대 4배이며, 반지름은 11에서 44까지 증가합니다. 보이는 원과 실제 충돌 범위가 함께 커져 좁은 틈을 통과하기 어려워집니다. 진화 버튼을 누르지 않고 에너지만 모으거나, 영입과 부하 수 증가만으로는 대장이 커지지 않습니다.

커질수록 기본 이동 속도도 높아집니다. 현재 지름 배율의 제곱근을 적용해 2배 크기에서 약 1.41배, 3배에서 약 1.73배, 4배에서 2배 속도가 됩니다. 이동 업그레이드가 없을 때 순항 속도는 112에서 최대 224까지 올라가고, Alignment와 가속 효과는 그 위에 곱해집니다. 추진력·제동력과 부하의 가속 한계도 함께 늘어 무리 안에서 빠져나오고 부하들이 따라갈 수 있게 합니다. 크기가 자라는 동안 속도도 점진적으로 오르며, 선회 관성과 회전 한계는 유지됩니다. 큰 대장이 테두리 바깥으로 전진할 때에는 남은 회전 공간에 맞춰 기존 제동 한계 안에서 감속하므로, 빠른 가속 때문에 경계에 붙잡히지 않습니다.

진화를 선택한 뒤 실제 플레이 시간 1초에 걸쳐 커집니다. 일시정지·선택 중에는 크기도 멈춥니다. 커지는 테두리 때문에 새 충돌이 생길 때는 확장만 기다리며, 기존 몸으로 적에게 부딪히면 그대로 사망합니다. 큰 대장 뒤에서는 부하가 여유를 두고 따라오고, 대장의 몸 안에 닿는 먹이도 수집합니다. 진화 화면에서 다음 크기, 일시정지 기록에서 현재 크기를 확인할 수 있습니다.

1. 맵에는 기본 먹이(시드)가 없으며 시간이 지나도 생기지 않습니다. 누가 처치했든 적의 잔해를 직접 흡수해야 경험치가 오르고, 흡수 가치 4당 개체가 한 마리 합류합니다. 처치만 하고 먹지 않으면 경험치를 얻지 않습니다.
2. 진화 에너지가 모이면 버튼이 활성화됩니다. **진화하기 / E**를 누르면 시간이 멈추고 능력 3개 중 하나를 선택합니다. 첫 진화는 넓게 퍼지기·함께 뭉치기·더 빨리 가기를 제시합니다.
3. 적 머리를 내 군체로 유도해 적을 해체하고 잔해를 흡수합니다. 적끼리도 같은 충돌 규칙을 따르며 모든 적 사망에 잔해가 남습니다. 처치 수는 내가 처치했을 때만 오르고, 잔해는 먼저 흡수한 군체가 차지합니다.
4. 기록 도전에서는 작은 적이 시작 비행 경로 뒤쪽을 가로지릅니다. 내 군체로 적 머리를 막고 잔해를 흡수하는 첫 기회입니다. 시간에 따른 무료 경험치나 자동 처치는 없으며, 실제 이동·충돌·흡수 규칙을 따릅니다. 모든 단계의 진화 비용을 기존의 3배로 높였습니다. 첫 진화에는 진화 에너지 18이 필요하고, 다음 진화에는 추가로 81, 그다음에는 114가 필요합니다. 개체 추가는 기존처럼 흡수 가치 4당 한 마리입니다.
5. 기록 도전의 난이도는 15·30·50·75·110초에 올라갑니다. 첫 추가 적은 7초에 등장하며, 이후 간격은 4초에서 최소 1.8초까지 줄어듭니다. 적 수는 최대 15개 군체로 제한하고, 크기·속도와 추격형·대형 비중을 높입니다. 새 적은 플레이어와 거리를 확보해 등장하고 기존 충돌 유예를 적용합니다.
6. 오래 버티면 계속 진화하며 도전할 수 있습니다. 사망하면 생존 시간을 0.1초 단위로 보여주고, 버튼 한 번 또는 R로 바로 다시 시작합니다. 기록 도전의 최고 기록은 기존 모드와 별도로 저장됩니다. 연습 결과는 생존 기록에 반영하지 않습니다.

긴 생존과 빠른 플레이는 각각 30분·3분에 승리하며 6단계가 5분·30초 간격으로 진행됩니다. 두 모드도 진화 비용이 기존의 3배이며, 첫 진화에는 진화 에너지 48이 필요합니다. 모든 모드에서 진화를 고르는 동안 시간이 멈춥니다.

한 판에서 선택한 진화는 다음 판에 초기화됩니다. 개인 최고 시간·소리 설정·플레이어 식별 정보·미전송 기록은 브라우저에, 등록된 랭킹은 서버에 저장합니다.

군체에는 고정 대형이나 개체별 지정 자리가 없습니다. 각 개체는 자신의 시야 안에서 가까운 이웃 최대 7마리와 방향·중심을 맞추고, 너무 가까운 개체와는 거리를 벌립니다. 머리를 볼 수 있는 개체가 먼저 반응하고 나머지는 이웃의 움직임을 따라갑니다. 개별 속도·가속·회전 한계가 있어 급회전과 가속 시 흐름이 달라집니다. 머리에 가까운 이웃의 흐름에 더 큰 비중을 주어 방향·가속·결집이 가까운 개체부터 전파됩니다. 결집은 속도와 이웃 간격을 줄이고, 놓으면 다시 펼쳐집니다. 카메라는 머리와 연결된 군체의 중심을 함께 따라갑니다. 기본 화면은 군체를 조금 가까이 보여주며, 진화로 대장이 커질수록 화면을 조금씩 넓혀 큰 몸과 무리가 잘 보이게 합니다. 시작 화면의 군체도 같은 시뮬레이션으로 움직입니다.

직진 중에는 대장이 앞쪽을 유지합니다. 뒤따르는 개체의 기본 순항 성향을 앞선 흐름보다 약 6% 낮추고, 간격이 벌어지면 가까운 이웃을 통해 따라붙게 합니다. 대장의 중심으로 몰리는 대신 뒤쪽 흐름을 따르며, 양옆으로 퍼질수록 조금 더 뒤에 머물러 느슨한 삼각형처럼 펼쳐집니다. 선회 중에는 이 성향을 약하게 하고 방향 동조를 우선해, 곡선을 따라 흐트러졌다가 직진하면서 다시 펼쳐집니다. 지정 자리나 좌표 보정은 사용하지 않으며 적 군체에도 같은 규칙이 적용됩니다.

## 연결과 소속

머리부터 가까운 동료를 거쳐 연결되는 개체만 내 군체입니다. 길게 늘어진 날개도 동료끼리 연결되어 있으면 유지됩니다. 연결이 끊긴 개체나 하위 무리는 **즉시 무소속**이 됩니다.

- 무소속 개체는 회색으로 표시되며 군체 수·먹이 흡수·플레이어 처치 판정·카메라 범위에서 빠집니다. 무소속 개체 자체는 머리에 위험하지 않습니다.
- 떠나던 위치와 속도를 유지하고 주변 무소속 이웃과 움직입니다. 원래 머리로 향하는 원격 복귀 유도는 없습니다.
- 가까운 군체와 일정 시간 함께 움직이면 그 군체에 합류할 수 있습니다. 원래 소속에 대한 우선권은 없으며 플레이어와 적 모두 같은 규칙을 따릅니다.
- 일시정지 기록의 `누적 이탈`은 이번 판에서 연결이 끊겨 떠난 누적 개체 수입니다.

## 군체의 동요와 이탈

주변에서 함께 움직이는 적 군체는 고립된 개체를 영입할 수 있습니다. 전체 규모로 영입 자격을 제한하지 않습니다. 가까운 적의 수와 거리·진행 방향을 주변 동료 수·머리의 보호·결집 상태와 비교합니다. 전체 규모와 진화는 제한된 보정만 주므로 작은 군체도 대형 군체의 늘어진 가장자리를 노릴 수 있습니다. 서로 반대 방향으로 스치는 접촉은 영입 압력을 만들지 않습니다.

양쪽 개체를 같은 거리 가중치로 비교합니다. 가까운 개체는 강하게, 먼 개체는 약하게 계산하며 영입 대상 자신은 방어 인원에 포함하지 않습니다. 공격 압력에 고정 상한을 두지 않고, 전체 규모 보정은 ±5% 이내로 제한합니다. 따라서 적 전체가 커도 꼬리 끝에서 작은 무리가 더 촘촘하게 모이면 영입할 수 있습니다. 머리 근처나 결집한 적은 여전히 보호받습니다.

- 동요 중인 개체는 적 쪽으로 움직이며 색이 서서히 바뀝니다. 금색 원과 HUD의 `동요` 숫자로 확인할 수 있습니다.
- 우리 무리를 따라오는 적·무소속 개체는 초록 진행 원과 HUD의 `합류 중` 숫자·가장 많이 진행된 대상의 백분율로 확인할 수 있습니다. 적 꼬리 옆에서 같은 방향으로 함께 날아 국소적인 우세를 유지하세요. 머리가 적 몸통에 닿으면 여전히 사망합니다.
- 동일한 방향으로 우세한 흐름이 계속되면 기본 약 2~6초에 걸쳐 적 군체로 소속이 바뀝니다. 순간 접촉으로 바로 바뀌지 않습니다.
- 잠깐 접촉이 끊겨도 진행도는 서서히 감소하며, 같은 군체를 다시 만나면 남은 진행도부터 이어집니다. 원래 군체에서 떨어져 무소속이 되어도 주변 흐름은 계속 감지합니다. 무소속 직후 0.65초 동안 소속 확정만 유예하며, 이미 쌓은 영입 진행도를 초기화하지 않습니다. 충분히 끌려온 뒤에도 새 군체와 실제 연결이 생겨야 합류합니다.
- 소속이 바뀌기 전에 적과 거리를 벌리거나 머리·동료 가까이 모이면 동요가 가라앉습니다. Cohesion은 결집과 이탈 저항을 함께 높이고, 공격할 때는 가까운 상대를 데려오는 압력도 단계당 12%씩 높입니다. 방향과 접촉 조건은 그대로 필요합니다.
- 적 가장자리에 국소적인 우세를 만들면 내 규모가 작아도 영입할 수 있습니다. 영입과 이탈 자체로 진화 에너지·처치 보상을 얻지는 않습니다. 진화 에너지는 전투 잔해를 흡수해서 모읍니다. 방어자의 Cohesion은 받는 영입 압력과 소속 변경 속도를 낮추며, 고립된 개체를 무조건 면역으로 만들지는 않습니다.
- 소속이 바뀐 개체는 2초간 머리 충돌과 재전향 판정을 유예합니다. 이후에는 새 소속의 몸통으로 충돌 판정합니다. 개체는 이동 중인 위치와 속도를 유지하며, 군체당 최대 160마리를 넘지 않습니다. 소속 변경이 끝나기 전이라도 원래 무리와 연결이 끊기면 즉시 무소속이 됩니다.

## 적의 행동과 전장 경쟁

적도 플레이어와 같은 선회 관성·각가속도·가속 에너지·감속·결집·테두리 흐름을 사용합니다. 크기 유형에 따라 순항 속도는 다르지만, 급회전이나 가속으로 공통 제약을 우회하지 않습니다. 적은 약 0.35~0.6초 간격으로 주변 640 범위의 머리와 먹이를 관찰하며, 플레이어의 입력이나 시야 밖 목표를 읽지 않습니다. 이동 전 상태에서 판단하므로 가속·선회에 반응할 시간이 생깁니다.

- **수집형**: 가까운 잔해를 우선하고 먹이가 없으면 탐색하거나 기회를 노립니다.
- **추격형**: 고립된 머리의 현재 진행 방향을 예측해 앞을 차단합니다. 플레이어뿐 아니라 다른 적도 노립니다.
- **보존형**: 늘어지거나 동요하는 동료가 있으면 감속·결집하고, 가까운 무소속 개체를 회수합니다.
- 모든 성향은 앞길이 위험하면 감속하고 회피합니다. 머리 위에 성향과 현재 행동이 표시되며 가속은 밝은 바깥 원, 결집은 머리 가까운 원으로 표시됩니다. 내 군체의 연결이 끊어지기 가까워지면 금색 점선이 나타납니다.

먹이는 플레이어와 적 모두 머리와 연결된 몸통으로 수집합니다. 접촉한 개체가 우선하고, 여러 군체가 경쟁하면 가까운 개체가 차지합니다. 정확히 같은 거리에서는 먹이별로 우선순위를 나누며 업데이트 순서로 플레이어가 독점하지 않습니다. 흡수 전에는 천천히 끌려오므로 다른 군체가 가로챌 수 있습니다. 적도 흡수 가치 4당 한 마리씩 성장하며 최대 160마리를 넘지 않습니다. 기본 먹이는 자동 생성하지 않습니다.

| 진화 | 효과 |
| --- | --- |
| Separation · 넓게 퍼지기 | 분리 반경 +18%, 개체 크기 +4% |
| Cohesion · 함께 뭉치기 | 이웃 결집력 +24%, 가까운 상대 영입 압력 +12% (5단계에서 +60%), 선회 능력 +10% (5단계에서 최대 +50%), 이탈 저항 증가 |
| Alignment · 더 빨리 가기 | 이동 속도 +7%, 이웃 방향 동조 +30% |
| Absorption · 먹이 끌어오기 | 먹이 흡수 반경 +30% |
| Proliferation · 친구 늘리기 | 개체 +8, 진화 에너지 획득량 +15% |
| Endurance · 오래 힘내기 | 가속 소모 −12%, 에너지 회복 +18% |

수치는 기본값 기준 합산이며 각 능력은 최대 5단계입니다. 플레이어 군체는 최대 160마리입니다. 모든 능력을 키운 뒤에도 진화 버튼으로 에너지를 사용해 가속 에너지를 회복하고 친구 한 마리를 추가합니다(160마리 상한).

## 구현

- `src/engine.mjs`: 렌더링과 독립된 시뮬레이션. 공간 격자와 개별 시야를 이용해 가까운 이웃을 찾고 separation·cohesion·alignment를 가속도에 합산합니다. 모든 개체는 같은 이전 프레임을 읽고 다음 상태를 함께 적용하며, 배열 순서에 따른 자리 배정은 없습니다. 상대 이동을 고려한 swept-circle 충돌 검사로 빠른 머리가 군체를 통과하지 않도록 합니다.
- `src/app.mjs`: Canvas 렌더링, 고정 60 Hz 게임 루프, 입력, UI, 선택적 합성 효과음.
- `src/scenery.mjs`: 월드에 고정된 지형 윤곽, 먼 안개, 가까운 입자로 이동과 선회를 보여줍니다. 입자의 잔상은 카메라의 실제 이동 속도·방향에 반응하며, 지형은 같은 위치에 돌아오면 같은 모습으로 보입니다. 모두 장식이며 충돌·먹이·경험치 판정에 영향을 주지 않습니다. 동작 줄이기 설정에서는 입자 잔상과 추가 시차를 끕니다.
- `style.css`, `index.html`: 데스크톱·모바일 화면 및 키보드로 접근 가능한 진화·일시정지 화면.
- `server/local.mjs`: 게임 정적 파일과 랭킹 API를 제공하는 Node.js 서버. `server/api.mjs`의 동일한 로직을 `server/worker.mjs`에서 D1에 연결할 수 있습니다.
- `src/ranking.mjs`, `src/identity.mjs`: 닉네임·고유번호·미전송 기록 보관과 자동 재전송.
- `tests/ranking.test.mjs`: 이름 중복과 변경·고유번호 충돌·소유권 검증·최고 기록 갱신·모드 분리·중복 요청·상위 10명 밖 내 순위·영구 저장·오프라인 복구 검증.
- `tests/engine.test.mjs`: 충돌, 성장, 시간 정지, 진화, 승리 조건 등 핵심 규칙 검증.
- `tests/evolution.test.mjs`: 진화 준비 중 비행 유지·수동 시작·에너지 이월·연속 선택 방지·진화 조건과 새 판 초기화 검증.
- `tests/head-growth.test.mjs`: 레벨별 대장 성장·4배 상한·성장 유예와 실제 충돌·큰 대장과 부하의 간격·영입 강화 검증.
- `tests/growth-flight.test.mjs`: 성장에 따른 속도 증가·이동 업그레이드와 가속의 중첩·추진과 제동 한계·큰 대장의 군체 내 탈출과 부하 연결 유지 검증.
- `tests/challenge.test.mjs`: 첫 교전부터 실제 흡수·진화까지, 빠른 난이도 진행, 끝없는 생존, 안전한 등장, 재도전 초기화와 기존 모드 분리 검증.
- `tests/influence.test.mjs`: 적 추종·소속 변경·동요 해소·저항·개체 수 보존·충돌 유예 검증.
- `tests/recruitment.test.mjs`: 짧은 접촉 단절·무소속 전환 중 영입 연속성·자연스럽게 형성된 12 대 64 무리의 실제 비행과 충돌을 포함한 꼬리 영입·접촉 대기·동요 해소 검증.
- `tests/control.test.mjs`: 결집·감속·회전 전파·연결 단절·무소속 행동·재합류·연습 모드 검증.
- `tests/tactics.test.mjs`: 국소 영입과 대응·공통 비행·성향과 시야·전장 잔해 경쟁 검증.
- `tests/flight.test.mjs`: 선회 관성·반대 조작·유턴·진화 상한·가속 시 회전 반경·테두리 비행 검증.
- `tests/leadership.test.mjs`: 군체 규모별 선두 유지·뒤로 넓어지는 흐름·진화와 가속 중 선두 유지·선회 후 재결집·적의 선두 유지 검증.

전체 테스트와 로컬 랭킹 서버에는 Node.js 24 이상이 필요합니다. 배포된 게임을 방문하는 플레이어에게는 브라우저만 필요합니다.

```sh
node --test tests/*.test.mjs
```

## 프로토타입 범위

현재 버전은 이동 감각과 군체 충돌·성장·진화의 기본 재미를 검증하기 위한 것입니다. 영구 성장, 여러 캐릭터, 보스 전용 패턴, 저장 후 이어하기는 포함하지 않습니다. 진화 비용이 3배로 늘어 첫 잔해 몇 개만으로는 준비되지 않으며, 더 모아야 합니다. 실제 진화 시점은 플레이어가 충분한 에너지를 모으고 버튼을 누르는 때입니다. 자동 검증은 사람의 평균 생존 시간이나 목표 난이도를 입증하지 않으며, 실제 플레이로 회피 여유·진화 선택과 장기 생존 밸런스를 계속 조정해야 합니다.
