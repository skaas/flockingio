# 폴른 히어로즈 · FALLEN HEROES

지휘기 한 대를 조종하고 자율 드론 편대로 적의 진로를 막는 실시간 멀티플레이 브라우저 게임입니다. Colyseus 서버의 공개 전장 한 개에 접속하며, 서버와 브라우저가 같은 결정론적 시뮬레이션을 계산합니다. 게임 이용자는 별도 회원가입 없이 이름을 정해 출격합니다.

서버 연결과 실행은 [Colyseus 배포 안내](docs/colyseus-deployment.md), 인원과 접속 규칙은 [멀티플레이 방 규칙](docs/multiplayer-room.md)을 참고하세요. 로컬 검증과 실제 Cloud 배포는 별개이며, 유료 서버 생성·배포는 자동으로 실행하지 않습니다.

## 편대전 — 현재 플레이

**자리 잡기 → 적 지휘기의 앞길 차단 → 격추 → 회색 드론 확보 → 다음 교전.** 시작 화면에서 같은 전장에 접속합니다. 신규 입장과 재출격은 드론 4기로 시작하며, 적 지휘기가 아군 드론에 부딪히면 격추됩니다. 내 지휘기도 같은 충돌 규칙을 따르고 지휘기끼리 충돌하면 양쪽 모두 격추됩니다.

격추된 적의 드론은 그 위치에 회색으로 호버링합니다. 합류가 완료될 때까지 이동하지 않으며, 가까이 머물러 통제권을 확보하면 다시 비행합니다. 다른 적도 확보할 수 있습니다. 살아 있는 지휘기와 연결만 끊긴 드론은 계속 비행합니다. 아군과 적 모두 합류로 성장합니다. 방에는 사람과 AI를 합쳐 살아 있는 편대를 최소 5개 유지하며, 접속자와 살아 있는 편대의 정원은 각각 30입니다. 사람이 5명 이상 살아 있으면 죽은 AI를 보충하지 않습니다.

편대전에서는 빠르게 선회할 때 드론이 이전 진행 방향으로 더 길게 흐르는 **드리프트**를 실험합니다. 지휘기는 기존처럼 움직이고, 드론이 뒤늦게 꺾이며 꼬리를 휘두릅니다. 직진하거나 기존 오른쪽 버튼 감속으로 회복할 수 있습니다. 조작과 지휘기의 가속·브레이크는 변경하지 않았습니다.

시설 폭격·대공포·개량 선택·제한 시간·일시정지는 없습니다. 한 사람이 격추되어도 방의 전투는 계속됩니다. 우측 상단 **편대 순위**는 살아 있는 지휘기들의 현재 드론 수를 비교하며, 내 행을 강조합니다. 회색 드론은 합류한 뒤에만 집계됩니다. 개인 결과 화면에는 최대 드론·격추·생존 시간이 표시되며, 재출격하면 같은 방에서 드론 4기로 다시 시작합니다. 나가기·접속 끊김 시 기존 편대는 내부 AI가 이어받고, 돌아온 사람에게 이전 편대의 조작권이나 성장을 돌려주지 않습니다.

[편대전 설계와 플레이 확인 기준](docs/fleet-battle-design.md)을 따릅니다. 구현과 전용 수치는 `src/fleet-battle.mjs`에 있으며 기존 비행·충돌·합류 계산을 재사용합니다. 폭격 출격과 옛 순위·재생의 화면 진입은 제거했습니다. 기존 저장 기록과 서버 데이터는 보존하며, 현재 편대전은 여기에 기록하지 않습니다.

## 보관된 폭격 출격 설계

아래 폭격·개량·기여도·재생 설명은 이전 구현의 기록입니다. 현재 화면에서 실행할 수 없으며, 공통 실행·개발 정보와 과거 동작을 확인하기 위해 보존합니다.


**출격 → 시설 제압·적 격추 → 전사 또는 시간 종료 → 기여도 기록 → 다음 출격.** 최대 5분 안에 적극적으로 공격해 높은 기여도를 기록하는 점수 경쟁입니다. 5분 생존은 승리 조건이 아닙니다. 영웅은 인물, 지휘기는 조종하는 기체, 출격은 한 번의 플레이, 전쟁 기여도는 전투 성과 점수입니다. 문구는 행동과 실제 결과만 표시합니다.

[5분 출격 밸런스 설계](docs/five-minute-balance-plan.md)에 선택의 위력과 시간대별 압박을 정리했습니다. [현재 전투 규칙](docs/current-rules.md)이 구현의 기준이며, 핵심 수치는 `src/rules.mjs`에 정의합니다. [콘셉트 리뷰와 용어 기준](docs/concept-and-terms.md)에 남은 설계 과제를 정리했습니다.

- **전쟁 기여도:** 진지 제압 1,000점 + 적 지휘기 격추 200점. 시설은 제압했을 때만 기여도를 얻습니다. 시간만 버티는 행동에는 점수가 없습니다.
- **출격 기록:** 이름, 전쟁 기여도, 제압·격추 내역이 먼저 보입니다. 피격 원인·출격 시간·장비는 펼쳐서 볼 수 있습니다.
- **기억의 축적:** 이 브라우저에 전사 횟수·총출격 수, 누적 기여도, 최고 기여도와 최근 50건을 저장하고 **전장의 영웅들 → 내 출격**에서 최근 50건을 볼 수 있습니다. 시작 화면에는 제목·이름과 편대전 시작·폭격 출격 버튼을 표시합니다. 당시 이름을 보존하며 훈련·중도 포기·기록 재생은 기록하지 않습니다. 저장이 막히면 이번 방문 동안 유지합니다. 전장은 출격마다 새로 시작하며 누적 기록은 영구 능력 강화가 아닙니다.
- **전장의 영웅들:** 기여도 순위와 내 출격을 탭으로 전환하며, 순위·이름·제압·격추·출격 시간·전쟁 기여도를 한 행에 표시합니다. 내 행만 강조하고 재생은 행 끝의 작은 버튼으로 제공합니다. 닫기 또는 Esc로 돌아갑니다. 서버에서도 전쟁 기여도순으로 정렬합니다. 동점은 출격 시간·최대 편대·격추·먼저 달성한 시각·플레이어 식별자순입니다. 이전 생존 기록은 삭제하지 않고 별도 표시해 새 전쟁 기여도 기록 뒤에 둡니다. 첫 전쟁 기여도 제출로 이전 생존 최고 기록을 교체하며, 같은 출격의 재전송은 처음 기록만 반영합니다.

전장에서 시설 폭격 목표가 전달되면 시험 운용 중인 지휘기와 자율 드론 편대가 출격합니다. 플레이어는 지휘기의 비행 경로를 조종하고, 드론은 가까운 이웃의 방향과 간격을 따라 움직입니다. 목표 구역에 드론이 진입하면 그 드론에서 시설로 폭탄을 투하합니다.

- **지휘기:** 플레이어의 조종 대상. 쌍발 추진기, 고정익 기체와 두 줄의 비행운으로 표시합니다. 장비를 개량할 때 모듈이 확장됩니다.
- **자율 드론:** 주변 동료의 움직임에 반응하는 flocking 비행. 제공된 기체 이미지와 편대 색상으로 표현합니다. 시작 4기, 편대당 최대 16기이며 적 편대의 드론도 대폭 줄였습니다.
- **회수 부품:** 지상 표적과 적 기체의 잔해에서 수집해 장비를 개량합니다. 드론은 ‘드론 추가’를 선택할 때 4기씩 합류합니다.
- **통제권 확보:** 적 후방 드론 옆에서 함께 비행해 연결을 확보합니다. 금색 표시는 적의 통신 교란, 회색 드론은 연결 상실 상태입니다.
- **시설 폭격:** 목표 좌표 수신, 드론 진입과 폭탄 투하, 진지 제압과 다음 좌표 갱신으로 이어집니다.

별도 브리핑 없이 바로 출격하고, 첫 요청 좌표와 지휘기가 함께 보이도록 화면을 잡습니다. 폭격 목표 카드에는 좌표·방향·거리, 시설 피해, 제압한 진지 수와 부품 보상을 표시합니다. 적 레이더를 피하며 지원을 마치면 다음 좌표가 도착하고, 전사하거나 시간이 끝나면 영웅의 이름·전쟁 기여도와 다음 출격을 표시합니다. 기존 폭격 전투와 재생은 현재 규칙 18만 지원합니다. 이전 규칙을 실행하는 코드는 제거했으며 옛 출격의 점수와 이름은 유지합니다. 지상군의 전진이나 전선 변화, 진입·이탈에 따른 별도 공격 단계는 아직 구현하지 않았습니다. 내부 코드의 `boids`, `food`, `xp`, `evolution` 식별자는 기존 저장·테스트와의 호환성을 위해 유지합니다.

## 실행

Node.js 22 이상이 필요합니다. 이 폴더에서 다음을 실행한 뒤 <http://127.0.0.1:2567>을 여세요. 서로 다른 브라우저나 탭에서 접속하면 같은 방에 입장합니다.

```sh
npm ci
npm run build
npm start
```

이 서버는 게임 파일과 실시간 통신을 함께 제공합니다. 방은 접속자가 없어도 AI 전투를 계속합니다. `PORT`로 포트를 바꿀 수 있습니다. 서버를 재시작하면 새 전장이 생성됩니다. `index.html`을 직접 여는 방식은 지원하지 않습니다. 이전 기여도 순위 API용 서버는 `npm run start:legacy`, 이전 Sites 패키징은 `npm run build:sites`로 유지합니다. 아래 기여도 순위·출격 재생 설명은 보관된 기능이며 현재 멀티플레이 기록을 업로드하지 않습니다.

## 이름과 기여도 순위

- 첫 화면에 준비된 이름을 직접 고칠 수 있습니다. **다른 이름**으로 새 이름을 제안받거나 바로 **출격**할 수도 있습니다. 기존 브라우저에 저장한 이름은 유지합니다. 화면에는 이름을 표시하며, 고유번호는 이름의 보조 정보로 제공합니다. 같은 이름도 서로 다른 플레이어입니다.
- 플레이어 식별자와 비밀 토큰은 이 브라우저에 저장합니다. 이름을 바꾸어도 고유번호와 기록은 유지됩니다. 다른 기기·브라우저를 쓰거나 브라우저 데이터를 삭제하면 새 플레이어가 됩니다. 계정 복구나 기기 간 로그인 기능은 없습니다.
- 시설 폭격 출격이 끝나면 전쟁 기여도 기록을 자동 등록합니다. 중도 포기는 등록하지 않습니다. 전쟁 기여도로 비교하고 동점일 때 출격 시간을 0.1초 단위로 비교합니다.
- 플레이어당 시설 폭격 출격 최고 기여도 한 줄을 표시합니다. 상위 10명과, 10위 밖일 때 내 순위를 확인할 수 있습니다. 이전의 이름 없는 브라우저 최고 기록은 자동으로 기여도 순위에 옮기지 않습니다.
- 연결 실패 시 종료된 출격 기록과 재생 데이터를 브라우저에 대기 저장하고 최대 30초 간격으로 재시도합니다. 새로고침·다음 출격·기여도 순위 새로고침 때도 재전송합니다. 같은 출격 번호의 중복 요청은 최초 기록 한 번만 반영합니다. 브라우저 저장이 차단되면 이번 방문 동안만 대기 기록을 보관합니다.
- 서버 데이터는 `.data/ranking.sqlite`에 영구 저장하며, 같은 서버에 접속한 브라우저끼리 공유합니다. DB와 서버 소스는 웹으로 제공하지 않습니다. 다른 플레이어의 기록을 덮어쓰지 못하도록 서버는 토큰의 해시를 검증합니다. 기여도 순위 응답에 토큰을 포함하지 않습니다.

[Sites 주소](https://murmur-flock-survivor.skaparty.chatgpt.site)에 배포하도록 연결되어 있습니다. `server/worker.mjs`는 동일한 API를 D1의 `DB` 바인딩과 정적 파일의 `ASSETS` 바인딩으로 실행합니다. `.openai/hosting.json`은 사이트 연결과 D1 설정을 보관합니다. `npm run build:sites`는 Worker와 게임 정적 파일을 `dist`에 패키징합니다. 로컬 `.data`의 기록은 업로드하지 않으며, Sites 기여도 순위는 별도 데이터베이스를 사용합니다. 배포 후 게임과 기여도 순위의 실제 동작 검증은 사용자가 진행합니다.

이 기여도 순위는 시제품용입니다. 서버에서 입력 범위·모드·중복 요청·플레이어 소유권을 검증하지만, 전쟁 기여도의 원시 집계와 출격 시간 등 결과 자체는 브라우저가 전송합니다. 경쟁용 공개 기여도 순위의 점수 위변조 방지를 위해서는 서버 시뮬레이션이나 입력 재생 검증이 추가로 필요합니다.

## 마지막 출격

시설 폭격 출격을 끝내면 **마지막 출격**이 나타납니다. 시작 화면의 **마지막 출격**에서도 다시 볼 수 있습니다. 중도 포기는 저장하지 않으며, 새로 종료된 출격 기록은 이전 로컬 재생 데이터를 교체합니다. 브라우저 저장에 실패해도 현재 방문 중에는 재생할 수 있습니다.

종료된 출격은 전쟁 기여도와 함께 서버에도 재생 데이터를 보냅니다. 플레이어의 최고 시설 폭격 출격 기록에 해당하는 출격 재생만 기여도 순위에 표시하며, **재생** 버튼으로 다른 사람도 볼 수 있습니다. 목록에는 출격 재생 유무만 내려주며 버튼을 누를 때 기록 문자열을 가져옵니다. 재생 기록이 없거나 현재 규칙과 버전이 다른 점수에는 재생 버튼이 없습니다. 다른 버전의 기록을 직접 조회하면 재생 불가 이유를 반환합니다. 저장 문자열이 약 1.9 MB를 넘는 긴 판은 점수만 등록합니다. 서버는 형식과 점수 일치를 검사하지만, 편대 계산을 재실행해 점수의 진위를 검증하지는 않습니다.

출격 기록에는 각 출격의 난수 시드, 고정 60 Hz 계산에 입력된 방향·목표 좌표·가속·결집, 개량 요청과 선택 시점만 기록합니다. 같은 입력이 이어지면 한 구간으로 묶습니다. 영상이나 모든 드론의 위치를 저장하지 않고 편대 알고리즘을 다시 실행합니다. 재생 중 5초마다 편대 상태의 지문을 비교하고, 마지막에 출격 시간·적 지휘기 격추·최대 편대와 상태를 검증합니다. 일치하지 않으면 재생을 멈추고 알립니다. 재생은 새 점수나 기여도 순위를 만들지 않습니다.

이 방식은 동일한 게임 코드와 브라우저 환경에서 계산을 재현하는 첫 단계입니다. 전투 결과나 상태 지문에 영향을 주는 변경은 공통 규칙 번호를 올리고 이전 기록의 재생을 종료합니다. 다른 브라우저의 수치 계산 차이로 현재 기록도 검증에 실패할 수 있습니다. 실제 네트워크 플레이에는 버전 고정, 참여 중간 상태 전달, 지연 보정 및 서버 검증이 추가로 필요합니다.

## 조작

| 입력 | 행동 |
| --- | --- |
| 마우스 이동 | 지휘기가 포인터 방향으로 회전 |
| 왼쪽 버튼 유지 | 에너지를 소모해 가속 |
| 오른쪽 버튼 유지 | 감속·결집. 느리게 선회하면서 편대의 폭을 줄임 |
| 오른쪽 위 일시정지 / 계속하기 | 비행을 멈추거나 재개 |
| 개량하기 / 장비 카드 클릭 | 부품이 충분하면 개량 시작, 시간이 멈춘 동안 장비 선택 |
| 다음 출격 클릭 | 시설 폭격 출격을 즉시 다시 시작 |

마우스로 조작하는 데스크톱 게임입니다. 비행 키보드 단축키와 터치 조작은 제공하지 않습니다. 좌우 버튼을 함께 누르면 결집이 우선하며, 오른쪽 버튼을 놓으면 누르고 있는 왼쪽 버튼의 가속으로 돌아갑니다. 일시정지·개량·창 전환 시 누르고 있던 입력을 초기화합니다.

**출격**은 전투 시간 최대 5분 안에 폭격 목표를 파괴하고 전쟁 기여도를 쌓는 게임입니다. 전사 또는 시간 종료 때 획득한 기여도를 기록하며, 버티기만 해서는 점수를 얻지 못합니다. 드론 4기로 출발해 요청 구역에 진입하면 드론이 폭탄을 투하하고, 목표를 파괴하면 새 좌표가 도착합니다.

화면에는 남은 작전 시간·전쟁 기여도·편대 수·가속 에너지·개량 진행도를 표시하고, 통신 교란·합류 숫자는 해당 드론이 있을 때만 나타납니다. 격추·부품 회수·누적 연결 상실과 선택한 모든 능력은 **일시정지 → 출격 기록과 장비**에서 확인합니다. 게임은 1280×720, 16:9 전장을 창에 맞춰 비율을 유지하며 확대·축소합니다. 왼쪽에 폭격 목표, 아래에 세 가지 마우스 조작과 개량 버튼을 표시합니다.

부품을 흡수하면 **회수 부품**이 쌓입니다. 필요한 양을 모으면 화면 아래 **개량하기** 버튼이 나타납니다. 준비된 동안에도 비행은 계속되며, 버튼을 클릭하면 개량 선택창이 열립니다. 모아 둔 에너지는 사라지지 않고 계속 쌓입니다. 한 번 누를 때 한 단계만 개량하며, 남은 에너지로 다시 개량할 수 있어도 다음 버튼 입력을 기다립니다.

**도움말**에서 조작과 전투을 확인할 수 있습니다. 플레이 중에는 **일시정지 → 조작과 전투**을 이용하세요. 일시정지 화면에서 연 도움말은 닫아도 일시정지를 유지합니다. 도움말은 닫기, 일시정지는 계속하기 버튼으로 돌아갑니다. 기본 메뉴의 키보드 접근성과 대화상자 포커스 이동은 유지합니다.

지휘기는 계속 전진하며, 선회 속도가 서서히 쌓이고 줄어드는 관성이 있습니다. 반대 방향을 입력해도 기존 선회를 먼저 줄인 뒤 돌아섭니다. 입력 방향만 뒤로 돌린다고 급감속하지 않으며 실제 선회에 따른 감속은 작게 적용됩니다. 가속 목표 속도는 순항의 3.5배(기본 392)입니다. 추진력·제동력과 가속 에너지 소모는 유지하며, 드론의 추종 속도 한계는 함께 높였습니다. 가속할수록 더 큰 원을 그리고, 결집하면 감속을 통해 좁게 돕니다. 결집 자체가 선회 속도 상한을 올리지는 않습니다. 결집과 가속을 동시에 입력하면 결집이 우선합니다.

기본 최대 선회 속도는 초당 약 69도이고, 편대 강화 한 번으로 40% 높아져 약 96도가 됩니다. 각가속도·속도에 따른 선회 제한과 경계 회피는 유지합니다.

적의 **지휘기가 내 편대 드론에 닿으면 적이 격추**되고, **내 지휘기가 적 편대 드론에 닿으면 게임이 끝납니다**. **지휘기끼리 부딪히면 규모·속도와 관계없이 양쪽이 동시에 격추**됩니다. 이 충돌에는 승자가 없으며 플레이어 처치 수가 늘어나지 않습니다. 적끼리도 같은 규칙을 적용하고, 격추된 적은 기존처럼 전투 잔해를 남깁니다. 같은 순간 드론에도 닿았다면 지휘기 간 충돌을 우선합니다. 자신의 편대와 드론끼리의 접촉은 안전합니다. 테두리는 즉사 벽이 아니라 지휘기를 안쪽으로 돌리는 흐름입니다. 시작과 적 등장에는 짧은 충돌 유예가 있습니다.

## 고정 화면 기준

전장의 기준 해상도는 **1280×720, 16:9**입니다. 창의 크기와 기기 안전 영역 안에 맞춰 비율을 유지하며 확대·축소하고, 남는 공간은 어두운 여백으로 둡니다. 창이 넓어져도 추가 시야를 얻지 않으며 편대·목표·성장에 따른 기존 카메라 이동과 줌은 같은 기준으로 계산합니다. 고해상도 화면은 픽셀 밀도를 최대 2배까지 반영합니다.

마우스 위치와 피격 효과는 표시된 전장의 위치·배율에 맞춥니다. 창 크기·여백·픽셀 밀도가 바뀌면 누르고 있던 입력을 해제합니다. HUD와 메뉴 글자는 실제 표시 영역에 맞춰 배치하고, 844×390·667×375처럼 높이가 낮은 가로 화면에서는 작은 HUD와 스크롤 가능한 메뉴를 사용합니다. 모바일 가로 대응을 위한 화면 기반이며, 터치 비행 조작과 실제 모바일 기기 검증은 후속 작업입니다.

## 한 판의 흐름

바닥은 지상전이 진행 중인 전장입니다. 대공 포대, 대공 레이더 기지, 방공 지휘소의 **시설 폭격 목표 좌표**가 한 건씩 표시됩니다. 첫 요청은 대공 포대의 좌표입니다. 왼쪽 요청 카드의 격자 좌표·방향·거리, 주황색 구역과 미니맵으로 현장을 찾습니다.

- 반경 120의 요청 구역에 있는 **각 아군 드론이 시설에 직접 폭탄을 투하**합니다. 지휘기의 위치와 관계없이 드론마다 기본 0.88초, 고속 장전 선택 시 0.44초 간격으로 독립적으로 공격하므로, 참여하는 드론이 많을수록 총화력이 증가합니다. 폭탄과 발사음은 투하한 드론의 실제 위치에서 시작합니다. 비행 속도와 선회는 기존 조작을 따르며, 떨어져 무소속이 되거나 적에게 넘어간 드론은 참여하지 않습니다.
- 첫 20초 이후 폭격을 시작하면 가까운 적 편대가 드론을 공격하러 옵니다. 가까운 상대가 없으면 안전거리를 두고 접근 편대가 등장합니다. 요청당 한 번만 출격하며, 적 수 상한과 기존 충돌·회피·선회 규칙을 따릅니다. 출격한 편대는 12초 동안 드론을 우선 추격한 뒤 일반 행동으로 돌아갑니다.
- 마지막 내 드론이 구역을 나가면 새 폭탄 투하가 멈추고, 한 기라도 돌아오면 이어집니다. 이미 입힌 피해는 유지되고 투하한 폭탄은 원래 피해량으로 명중합니다. HUD와 지상 표시는 `드론 폭격 중`·`드론 진입 시 폭격`과 누적 시설 피해를 보여줍니다.
- 첫 시설의 내구도는 160이며 기본 폭탄 16발이 명중하면 잔해로 바뀌고 **부품 24~45**이 현장에 한 번 떨어집니다. 자동 지급하지 않으며, 기존 잔해처럼 회수하면 개량 자원이 늘어납니다. 다른 편대도 먼저 회수할 수 있습니다.
- 목표를 파괴한 뒤 2.8초 후 다음 폭격 목표 좌표가 알림음과 함께 갱신됩니다. 완료 표시는 3.5초 동안 남습니다. 새 시설은 등장 시간대에 따라 내구도 160·480·1,200·2,400·4,000·6,000을 적용합니다. 이미 나온 시설은 강화하지 않습니다. 기본 폭탄은 10의 피해를 입힙니다. 훈련에는 지상 작전이 없습니다. 일시정지·개량 선택·게임 종료 중에는 폭격도 멈춥니다.

지휘기는 개량할 때마다 기본 크기의 10%씩 커지되 최대 1.6배(반경 17.6)까지만 성장합니다. 표시와 실제 충돌 범위가 함께 커집니다. 부품만 모으거나 드론이 늘어나는 것으로는 지휘기가 커지지 않습니다.

크기 배율의 제곱근만큼 순항 속도가 증가합니다. 기본 112에서 최대 약 142이며 비행 속도 선택의 +28%와 가속이 그 위에 적용됩니다. 추진·제동과 드론 추종도 함께 조정되며 선회 관성·경계 회피를 유지합니다.

개량을 선택한 뒤 실제 플레이 시간 1초에 걸쳐 커집니다. 일시정지·선택 중에는 크기도 멈춥니다. 커지는 테두리 때문에 새 충돌이 생길 때는 확장만 기다리며, 기존 몸으로 적에게 부딪히면 그대로 격추됩니다. 큰 지휘기 뒤에서는 드론이 여유를 두고 따라오고, 지휘기의 몸 안에 닿는 부품도 수집합니다. 일시정지 기록에서 현재 크기를 확인할 수 있습니다.

1. 맵에는 기본 부품(시드)가 없으며 시간이 지나도 생기지 않습니다. 시설 제압 보상이나 적의 잔해를 직접 회수해야 개량 자원이 쌓입니다. 부품을 모아도 아군 드론이 자동으로 늘어나지 않습니다. 타격·처치만 하고 회수하지 않으면 개량 자원을 얻지 않습니다.
2. 부품이 모이면 **개량하기**로 전투를 멈추고 최대 3장 중 하나를 고릅니다. 공격·증원이 남아 있으면 최소 한 장을 보장하고 나머지를 중복 없이 무작위 추첨한 뒤 섞습니다.
3. 적 지휘기를 내 편대로 유도해 적을 해체하고 잔해를 흡수합니다. 적끼리도 같은 충돌 규칙을 따르며 모든 적 격추 시 잔해가 남습니다. 처치 수는 내가 처치했을 때만 오르고, 잔해는 먼저 흡수한 편대가 차지합니다.
4. 전방 대공 포대가 첫 목표입니다. 파괴한 잔해나 적 격추 잔해를 회수해야 강화할 수 있습니다. 선택 비용은 12·18·24·36·48·66·84·108·132·162·192이며 이후192를 유지합니다. 시간에 따른 무료 부품이나 자동 처치는 없습니다.
5. 45·90·150·210·255초에 다음 전투 단계로 진행합니다. 살아 있는 적 편대 상한은 2·3·4·5·6·7, 증원 간격은 10·8·6.5·5.5·4.5·3.5초입니다. 플레이어 장비에 따라 적을 즉시 강화하지 않습니다. 첫 두 정찰 편대는 멀리 진입하고 첫20초는 시설 요격을 유예합니다. 세부 수치는 [밸런스 계획](docs/five-minute-balance-plan.md)을 참고하세요.
6. 전사하거나 300초를 쓰면 출격을 종료하고 실제 제압·격추 기여도를 기록합니다. 시간 종료는 승리나 생존 보상을 주지 않습니다. 출격 시간·장비는 상세에서 보고 **다음 출격**으로 다시 시작합니다.

개량을 고르는 동안에는 시간이 멈춥니다. 현재 전투 엔진은 하나입니다. 내부 시간 제한 모드와 훈련도 같은 엔진을 사용하며 시작 화면에서는 편대전과 일반 폭격 출격을 제공합니다.

한 판에서 선택한 개량은 다음 판에 초기화됩니다. 출격 기록·최고 기여도·소리 설정·플레이어 식별 정보·미전송 기록은 브라우저에, 등록된 기여도 순위는 서버에 저장합니다.

편대에는 고정 대형이나 드론별 지정 자리가 없습니다. 각 드론은 자신의 시야 안에서 가까운 이웃 최대 7기와 방향·중심을 맞추고, 너무 가까운 드론과는 거리를 벌립니다. 지휘기를 볼 수 있는 드론이 먼저 반응하고 나머지는 이웃의 움직임을 따라갑니다. 개별 속도·가속·회전 한계가 있어 급회전과 가속 시 흐름이 달라집니다. 지휘기에 가까운 이웃의 흐름에 더 큰 비중을 주어 방향·가속·결집이 가까운 드론부터 전파됩니다. 결집은 속도와 이웃 간격을 줄이고, 놓으면 다시 펼쳐집니다. 카메라는 지휘기와 연결된 편대의 중심을 함께 따라갑니다. 기본 화면은 편대를 조금 가까이 보여주며, 개량으로 지휘기가 커질수록 화면을 조금씩 넓혀 큰 몸과 편대가 잘 보이게 합니다. 시작 화면의 편대도 같은 시뮬레이션으로 움직입니다.

직진 중에는 지휘기가 앞쪽을 유지합니다. 뒤따르는 드론의 기본 순항 성향을 앞선 흐름보다 약 6% 낮추고, 간격이 벌어지면 가까운 이웃을 통해 따라붙게 합니다. 지휘기의 중심으로 몰리는 대신 뒤쪽 흐름을 따르며, 양옆으로 퍼질수록 조금 더 뒤에 머물러 느슨한 삼각형처럼 펼쳐집니다. 선회 중에는 이 성향을 약하게 하고 방향 동조를 우선해, 곡선을 따라 흐트러졌다가 직진하면서 다시 펼쳐집니다. 지정 자리나 좌표 보정은 사용하지 않으며 적 편대에도 같은 규칙이 적용됩니다.

## 레이더와 대공포

적 시설의 포대는 락온할 때마다 **현재 단계에서 열린 사격 방식 중 하나**를 고릅니다. 한 번에 한 포대만 조준합니다. 노란 조준점은 추적 중이며, 붉은 원과 숫자는 폭발 위치와 순서입니다. 락온하면 HUD와 탄착점 옆에 사격 이름과 피하는 방법이 함께 표시됩니다.

| 사격 | 탄착점 | 맞는 비행 | 피하는 법 |
| --- | --- | --- | --- |
| 직진 예측 사격 | 현재 방향·속도로 계속 날아갈 항로에 3발 | 직진 | 방향 꺾기 |
| 좌선회 예측 사격 | 0.4초 뒤부터 왼쪽으로 계속 돈다고 본 호에 3발 | 왼쪽 선회 | 직진 또는 오른쪽 |
| 우선회 예측 사격 | 같은 방식으로 오른쪽으로 도는 호에 3발 | 오른쪽 선회 | 직진 또는 왼쪽 |
| 방사 사격 | 포대를 중심으로 지휘기의 현재 거리에 틈 없는 원형 탄막(8~16발 동시 발사) | 포대 주위 선회 | 원 선회를 멈추고 직진하거나 바깥으로 이탈 |

두 가지 이상 열린 뒤에는 같은 사격 방식이 연속으로 나오지 않습니다. 처음에는 직진 예측만 사용하고, 45초에 좌선회, 90초에 우선회, 150초에 방사 사격을 추가합니다. 사격 방식은 포대·사격 횟수·지휘기 위치로 정하며, 적 등장이나 부품 같은 전장의 난수를 쓰지 않습니다.

| 단계 | 동작 |
| --- | --- |
| 포착 | 시설 중심에서 300 이내 진입 시 추적을 시작합니다. |
| 추적 | 조준점은 초당 최대 135만큼 이동합니다. 지휘기에 충분히 가까워진 뒤 시간대별로 3.2~1.8초간 추적하면 락온합니다. |
| 예측 경고 | 현재 위치·속도와 고른 사격 방식으로 모든 탄착점을 고정합니다. 첫 발포 1.4~1초 전에 경고하며 이후 탄착점은 플레이어를 따라가지 않습니다. |
| 사격 | 예측 사격 세 가지는 0.36초 간격으로 3발, 방사 사격은 모든 포탄을 한 번에 발사합니다. 각 포탄은 0.65초 뒤 반경 36에서 폭발합니다. 직진 예측의 두 번째·세 번째 탄착점은 예상 항로 양옆으로 18씩 퍼집니다. 지휘기의 충돌 범위가 겹치면 격추됩니다. |
| 재장전 | 마지막 발사 뒤 4~2.6초간 조준을 멈춘 뒤 다시 추적합니다. 날아가는 포탄의 탄착점과 경고는 도착할 때까지 남습니다. |
| 추적 해제 | 시설에서 340보다 멀어지거나 시설이 파괴되면 추적과 남은 발사를 취소합니다. 이미 발사된 포탄은 도착하므로 계속 피해야 합니다. |

단계가 오르면 포착은 3.2초에서1.8초, 재장전은4초에서2.6초, 경고는1.4초에서1초까지 줄어듭니다. 조준 확정 시 경고·탄착점·재장전을 고정하여 단계 전환이 진행 중인 사격을 바꾸지 않습니다. 경고와 비행 시간을 합한 회피 시간은 최소1.65초입니다. 생성 보호·훈련 제외·드론 대공 피해 없음은 유지합니다.

HUD의 레이더 아이콘, 추적 진행 막대, 발포 전 남은 시간과 지도 위 조준점을 함께 표시합니다. 지휘기가 시설 중심 135 이내로 진입하면 상공 진입 사이렌이 울리며, 경계를 스칠 때 소리가 반복해서 켜지고 꺼지지 않도록 150 밖에서 해제합니다. 드론만 진입하면 사이렌은 울리지 않습니다.

추적·예측 항로·연속 사격·탄착은 고정 시간 간격으로 계산하며 일시정지와 개량 선택 중에는 함께 멈춥니다. 현재 기록은 각 드론의 다음 공격 시점, 모든 개량 단계, 시설 내구도·피해·폭탄별 피해량·아직 발사하지 않은 대공포 탄착점까지 검증합니다. 자동 증원·편대 공통 폭격·단발 대공포 등 과거 규칙 분기는 없습니다.

## 연결과 소속

지휘기부터 가까운 동료를 거쳐 연결되는 드론만 내 편대입니다. 길게 늘어진 날개도 동료끼리 연결되어 있으면 유지됩니다. 연결이 끊긴 드론이나 하위 편대는 **즉시 무소속**이 됩니다.

- 무소속 드론은 회색으로 표시되며 편대 수·부품 흡수·플레이어 처치 판정·카메라 범위에서 빠집니다. 무소속 드론 자체는 지휘기에 위험하지 않습니다.
- 떠나던 위치와 속도를 유지하고 주변 무소속 이웃과 움직입니다. 원래 지휘기로 향하는 원격 복귀 유도는 없습니다.
- 가까운 편대와 일정 시간 함께 움직이면 그 편대에 합류할 수 있습니다. 원래 소속에 대한 우선권은 없으며 플레이어와 적 모두 같은 규칙을 따릅니다.
- 일시정지 기록의 `누적 연결 상실`은 이번 판에서 연결이 끊겨 떠난 누적 드론 수입니다.

## 편대의 통신 교란과 이탈

주변에서 함께 움직이는 적 편대는 고립된 드론의 통제권을 확보할 수 있습니다. 전체 규모로 통제권 확보 자격을 제한하지 않습니다. 가까운 적의 수와 거리·진행 방향을 주변 동료 수·지휘기의 보호·결집 상태와 비교합니다. 전체 규모와 개량은 제한된 보정만 주므로 작은 편대도 대형 편대의 늘어진 가장자리를 노릴 수 있습니다. 서로 반대 방향으로 스치는 접촉은 통제권 확보 압력을 만들지 않습니다.

양쪽 드론을 같은 거리 가중치로 비교합니다. 가까운 드론은 강하게, 먼 드론은 약하게 계산하며 통제권 확보 대상 자신은 방어 인원에 포함하지 않습니다. 공격 압력에 고정 상한을 두지 않고, 전체 규모 보정은 ±5% 이내로 제한합니다. 따라서 적 전체가 커도 편대 후방에서 작은 편대가 더 촘촘하게 모이면 통제권을 확보할 수 있습니다. 지휘기 근처나 결집한 적은 여전히 보호받습니다.

- 통신 교란 중인 드론은 적 쪽으로 움직이며 색이 서서히 바뀝니다. 금색 원과 HUD의 `통신 교란` 숫자로 확인할 수 있습니다.
- 우리 편대를 따라오는 적·무소속 드론은 초록 진행 원과 HUD의 `연결 중` 숫자·가장 많이 진행된 대상의 백분율로 확인할 수 있습니다. 적 후방 드론 옆에서 같은 방향으로 함께 날아 국소적인 우세를 유지하세요. 지휘기가 적 드론에 닿으면 여전히 격추됩니다.
- 동일한 방향으로 우세한 흐름이 계속되면 기본 약 2~6초에 걸쳐 적 편대로 소속이 바뀝니다. 순간 접촉으로 바로 바뀌지 않습니다.
- 잠깐 접촉이 끊겨도 진행도는 서서히 감소하며, 같은 편대를 다시 만나면 남은 진행도부터 이어집니다. 원래 편대에서 떨어져 무소속이 되어도 주변 흐름은 계속 감지합니다. 무소속 직후 0.65초 동안 소속 확정만 유예하며, 이미 쌓은 통제권 확보 진행도를 초기화하지 않습니다. 충분히 끌려온 뒤에도 새 편대와 실제 연결이 생겨야 합류합니다.
- 소속이 바뀌기 전에 적과 거리를 벌리거나 지휘기·동료 가까이 모이면 통신 교란이 가라앉습니다. Cohesion은 결집과 이탈 저항을 함께 높이고, 공격할 때는 가까운 상대를 데려오는 압력도 한 번에48% 높입니다. 방향과 접촉 조건은 그대로 필요합니다.
- 적 가장자리에 국소적인 우세를 만들면 내 규모가 작아도 통제권을 확보할 수 있습니다. 통제권 확보와 이탈 자체로 개량 자원·처치 보상을 얻지는 않습니다. 개량 자원은 전투 잔해를 흡수해서 모읍니다. 방어자의 Cohesion은 받는 통제권 확보 압력과 소속 변경 속도를 낮추며, 고립된 드론을 무조건 면역으로 만들지는 않습니다.
- 소속이 바뀐 드론은 2초간 지휘기 충돌과 재전향 판정을 유예합니다. 이후에는 새 소속의 드론으로 충돌 판정합니다. 드론은 이동 중인 위치와 속도를 유지하며, 편대당 최대 16기를 넘지 않습니다. 소속 변경이 끝나기 전이라도 원래 편대와 연결이 끊기면 즉시 무소속이 됩니다.

## 적의 행동과 전장 경쟁

적도 플레이어와 같은 선회 관성·각가속도·가속 에너지·감속·결집·테두리 흐름을 사용합니다. 크기 유형에 따라 순항 속도는 다르지만, 급회전이나 가속으로 공통 제약을 우회하지 않습니다. 적은 약 0.35~0.6초 간격으로 주변 640 범위의 지휘기와 부품을 관찰하며, 플레이어의 입력이나 시야 밖 목표를 읽지 않습니다. 이동 전 상태에서 판단하므로 가속·선회에 반응할 시간이 생깁니다.

- **회수 편대**: 가까운 잔해를 우선하고 부품이 없으면 탐색하거나 기회를 노립니다.
- **요격 편대**: 고립된 지휘기의 현재 진행 방향을 예측해 앞을 차단합니다. 플레이어뿐 아니라 다른 적도 노립니다.
- **호위 편대**: 늘어지거나 통신 교란을 받는 동료가 있으면 감속·결집하고, 가까운 무소속 드론을 회수합니다.
- 모든 성향은 앞길이 위험하면 감속하고 회피합니다. 적 지휘기의 성향·행동 글씨는 표시하지 않으며 가속은 밝은 바깥 원, 결집은 지휘기 가까운 원으로 표시됩니다. 내 편대의 연결이 끊어지기 가까워지면 금색 점선이 나타납니다.

부품은 플레이어와 적 모두 지휘기와 연결된 드론으로 수집합니다. 접촉한 드론이 우선하고, 여러 편대가 경쟁하면 가까운 드론이 차지합니다. 정확히 같은 거리에서는 부품별로 우선순위를 나누며 업데이트 순서로 플레이어가 독점하지 않습니다. 흡수 전에는 천천히 끌려오므로 다른 편대가 가로챌 수 있습니다. 적도 흡수 가치 12당 한 기씩 성장하며 최대 16기를 넘지 않습니다. 기본 부품은 자동 생성하지 않습니다.

| 드론 공격력 | 폭탄 피해10 →20 |
| 쌍발 폭탄 | 드론당 한 번에1 →2발 |
| 고속 장전 | 간격0.88 →0.44초 |
| 드론 추가 | +4기, 최대3회·16기 |
| 드론 간격 | 분리 반경+72%, 드론 크기+16% |
| 편대 강화 | 결집+96%, 통제권 확보 압력+48%, 선회+40% |
| 비행 속도 | 순항+28%, 방향 동조+120% |
| 부품 수집 | 수집 반경+120% |
| 가속 강화 | 소모−48%, 회복+72% |

증원 외에는 각 한 번만 선택합니다. 위력·쌍발·고속 장전·첫 증원을 조합하면 같은 드론 참여율에서 이론 지속 화력이16배입니다. 실제 제압 속도는 표적 내구도·비행·참여율에 따라 다릅니다. 이미 투하한 폭탄과 시작한 재장전은 원래 값을 유지하며, 비행 중 피해가 충분하면 추가 투하를 멈춥니다. 모든 선택은 새로 합류한 드론에도 적용됩니다. 편대가 가득 차면 증원은 제외하며 모든 능력을 얻은 뒤에는 부품으로 가속 에너지만 회복합니다.

## 사운드

적 편대는 [세 조종사의 무전 12개](audio/Radio/README.md)로 행동을 알립니다. 승인한 강한 무전 효과와 목소리 −3dB를 적용했으며 자막은 없습니다. 가까운 적의 행동이 유지될 때만 들리고, 교신 간격을 제한하며 대공포 경고가 우선합니다. 초기 합성 음성과 비교본은 [샘플 에셋 목록](audio/samples/enemy-radio/README.md)에 별도로 보관하고 배포하지 않습니다.

`audio/Music`과 `audio/Sound`의 음원을 사용합니다. 첫 클릭 이후 소리가 시작되며, 처음 방문한 브라우저는 소리가 켜져 있습니다. 이전에 소리를 껐다면 그 설정을 유지합니다.

- 시작 화면에는 `musicMenu`, 전투에는 `musicGameplay`, 4번째 난이도 구간부터는 `musicBoss`가 반복 재생됩니다. 곡은 부드럽게 교차 전환하며 훈련은 기본 전투 음악을 유지합니다.
- 레이더 경고 수신기(RWR)처럼 적 레이더의 펄스 반복 주파수를 거친 버즈음으로 들려줍니다. 포대 근처에 들어가면 안테나가 한 바퀴 돌 때마다 탐색 레이더가 기체를 훑는 소리가 나고, 가까울수록 커집니다. 포착이 시작되면 짧은 버즈음이 진행도에 따라 빨라지고 음이 올라가며, 락온 순간 상승음과 함께 **끊기지 않는 연속음**으로 바뀝니다. 발포 후에는 빠르게 떨리는 발사 경고음이 포탄이 모두 떨어질 때까지 이어지고, 추적이 풀리면 하강음과 함께 즉시 끊깁니다. 락온 순간에는 해당 포대 방향에서 포탑이 선회하는 기계음(`turretOpen`)이 납니다. 경고음은 합성음이라 음원 로딩을 기다리지 않고, 헤드셋 소리처럼 잔향 없이 가운데에서 들립니다.
- 전장 배경은 여러 층으로 겹칩니다. `ambChaosSTLP` 반복음은 녹음 앞부분의 페이드인을 건너뛰고 매번 다른 지점에서 시작하며, 그 아래에 멀리서 계속되는 포격의 저음 울림을 합성해 깔아 둡니다. 먼 포대는 한 방향에서 2~4발을 불규칙한 간격으로 쏘고(`mortarExplode`·`explosionDark`·`explosionShockwave`), 먼 기관총은 서로 응사하듯 짧은 연사를 주고받으며(`minigunFireLP`·`turretFireLP`), 가끔 저격 총성(`sniperFire`)이 울립니다. 25~50초마다 헬기·건십이 멀리서 좌우를 가로질러 지나가며 도플러 효과로 음이 내려갑니다. 가까운 시설에서는 `infantryFire00`~`04` 총성이 나고, 난이도 구간과 시설 근접도에 따라 전투 빈도가 늘어납니다. 멀리서 난 소리일수록 고음이 줄고 야외 잔향(합성한 지형 반사음)이 많아져 거리감이 납니다. 배경 전투음은 동시에 6개까지만 재생해 플레이어의 전투음을 가리지 않습니다. 적 시설 상공에는 방향이 있는 `bossWarningSiren`이 울립니다. 락온·포탄 접근 중에는 음악과 환경음을 잠시 낮추고 새 배경 전투음을 쉬어 경고를 들려줍니다. 일시정지·훈련·게임 종료·음소거·다른 탭 이동 시 전장 반복음은 멈춥니다.
- 드론의 폭탄 투하·명중·시설 파괴에 박격포와 폭발음을 연결했습니다. 잔해 흡수, 합류·이탈, 가속·결집, 개량 준비·완료, 경고와 게임 종료에도 효과음이 납니다. 폭격음은 드론과 명중 위치에 따라 좌우와 음량이 달라집니다.
- 오른쪽 위 스피커로 전체 소리를 켜고 끕니다. **일시정지 → 사운드 설정**에서 배경음·효과음을 따로 조절하며, 설정은 브라우저에 저장합니다.
- 일시정지·개량 선택 중에는 전투 효과음을 멈추고 음악을 낮춥니다. 다른 탭으로 이동하면 모든 소리가 멈춥니다. 효과음의 반복 간격·동시 재생 수를 제한하고 압축기를 사용해 대규모 전투에서도 음악이 과하게 묻히지 않도록 했습니다.
- 오디오를 지원하지 않거나 일부 음원이 로드되지 않아도 게임은 계속됩니다. 선택된 음원만 로컬 서버에서 제공하고 배포 빌드에 포함합니다.

## 구현

- `src/rules.mjs`: 현재 규칙 번호·편대·공격·시설·대공포·기여도·비행의 핵심 수치.

## 프로토타입 범위

현재 버전은 강력한 단일 선택과 공격 조합, 최대5분의 기여도 경쟁을 검증하는 프로토타입입니다. 영구 성장·여러 캐릭터·보스 전용 패턴·저장 후 이어하기는 없습니다. 자동 테스트는 수치·충돌·시간 상한·재생의 일관성을 점검하며 사람의 난이도나 재미를 입증하지 않습니다. 실제 사람 플레이로 강화 전후 제압 속도·공격 빈도·회피 가독성·최종 기여도를 확인해야 합니다.

## 전장 이미지

지상 지형·건물·잔해·폭발은 `images/Hard Vacuum`의 원본 BMP에서 변환한 아틀라스를 사용합니다. `python3 scripts/convert-hard-vacuum.py`(Pillow, numpy 필요)가 색상 키 배경과 프레임 격자 점을 투명하게 처리하고 두 장의 PNG와 표를 만듭니다. 원본 파일은 변경하지 않으며 브라우저에는 변환 결과만 전송합니다.

- `images/hv/terrain.png`: 20px 지형 타일. 바이옴마다 기본 지형, 폭격으로 그을린 땅, 테두리가 있는 포탄 구덩이, 도로와 파손 도로, 그을린 땅을 지나는 도로의 전이 타일이 들어 있습니다.
- `images/hv/sprites.png`: 목표 시설(대공 포대 8방향, 레이더 기지·방공 지휘소 애니메이션)과 파괴 모습, 폐허·무너진 벽·잔해, 전차·장갑차·헬기 8방향, 불꽃, 12프레임 폭발, 구름 그림자.
- `src/hv-atlas.mjs`: 변환기가 생성하는 타일 번호·코너 마스크·스프라이트 좌표 표. 직접 수정하지 않습니다.

지휘기·드론 스프라이트는 기존 `images/Enemies/airEnemies0.png`, 요청과 목표 표시는 `missionBuilding0.png`와 `focusFire.png`를 계속 사용합니다. 이미지가 로드되지 않으면 지형은 색 면으로, 시설은 기존 도형으로 그려 플레이를 유지합니다. 로컬 서버와 빌드는 `src/sprites.mjs`에 명시한 이미지 5개만 정적 에셋으로 포함합니다.

그래픽 일부는 Daniel Cook(Lostgarden)이 공개한 Hard Vacuum 그래픽입니다. 배포할 때는 원작자를 표기하세요.

## 절차적 전장

출격마다 전장이 새로 생성됩니다. 출격 시드에서 별도의 지도 시드를 만들어 쓰므로 같은 출격 기록을 재생하면 같은 전장이 나타나고, 시뮬레이션 난수·충돌·전쟁 기여도에는 영향을 주지 않습니다. 지형과 장식은 비행을 막지 않습니다.

- **바이옴:** 초원 전선·사막 보급로·설원 방어선·암석 고원·산업 단지 중 하나. 우측 하단 미니맵 위에 작전 구역 이름과 구역 코드(예: `G-7F3A`)를, 일시정지·출격 상세에 같은 정보를 표시합니다.
- **전선:** 무작위 각도로 전장을 가로지르는 굽은 전선을 따라 그을린 땅, 포탄 구덩이, 차량 잔해와 화재가 모입니다.
- **도로:** 전선을 가로지르는 보급로 하나와 뒤쪽의 측면 도로 한두 개. 타일 격자를 따라 직선과 직각으로 꺾이며, 전선 근처에서는 도로 가장자리가 부서집니다. 도로 위로 전차·장갑차 행렬이 오갑니다.
- **거점:** 도로 옆의 건물 무리. 적 쪽 거점에는 일부 건물이 서 있고 나머지는 불타는 폐허와 무너진 벽입니다.
- **타일 조합:** 각 꼭짓점의 지형(도로·구덩이·그을린 땅)으로 네 모서리 마스크를 만들고 해당 전이 타일을 고릅니다. 원본 시트에 없는 대각선 조합은 생성 단계에서 없앱니다.
- **렌더링:** 지형과 건물은 640×640 단위 조각으로 한 번 그려 보관하고, 한 프레임에 최대 3조각만 새로 만듭니다. 차량 잔해·행렬·불꽃·연기·구름 그림자는 매 프레임 그립니다. 동작 줄이기 설정에서는 움직임을 멈춥니다. 원본의 밝은 색은 드론과 경고 표시가 잘 보이도록 어둡게 보정합니다.
- **제압 흔적:** 제압한 시설 자리에는 파괴된 시설과 그을음, 출격이 끝날 때까지 꺼지지 않는 불이 남습니다.
