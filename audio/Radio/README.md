# 적 편대 무전 — 게임 적용본

사용자가 승인한 세 조종사와 강한 무전 효과(v3, 목소리만 −3dB)를 사용합니다. 회수는 Enceladus, 요격은 Orus, 호위는 Algenib입니다. 각 편대에 차단·회수·재집결·회피 교신이 있어 총12개입니다. 파일과 대사는 [manifest.json](manifest.json)에 기록했습니다.

Google Gemini 3.8 Flash TTS로 생성하고 무전 효과를 미리 입힌 파일이며 게임 실행 중 외부 음성 API를 호출하지 않습니다.

살아 있는 적이 플레이어 반경650 안에서 행동을0.5초 이상 유지할 때 교신합니다. 출격 처음4초는 조용하며, 전체12초·같은 적20초·같은 편대와 대사30초 간격을 둡니다. 한 번에 한 명만 말하고 밀린 대사를 나중에 재생하지 않습니다. 레이더 락온·포탄 접근 시 교신을 끊습니다. 일시정지·개량·종료·음소거·다른 탭 이동 시 멈추며 훈련에서는 재생하지 않습니다. 자막이나 적 머리 위 글씨는 추가하지 않습니다.

직접 선택한 세 대사의 게임용 파일은 승인된 v3 파일과 바이트가 같습니다. 나머지9개는 동일한 목소리·연출 지시·가공 설정으로 추가 생성했습니다. 새9개 대사의 발음·연기를 별도로 청취 평가했다고 주장하지 않습니다. 원음과 요청 기록은 [제작 보관본](../samples/enemy-radio/google-tts/full-set)에 있습니다. 초기 시험본은 배포하지 않습니다.

## 아군 관제 교신

새 포격 요청은 관제 요청과 조종사 응답을 이어 붙인 `control-strike-request.ogg`로 알립니다. 대사는 “팔콘 원, 목표 좌표 전송. 타격 요청한다.” → “팔콘 원, 수신. 목표로 접근한다.”입니다. Orus와 Enceladus 음성을 사용하며, 기존의 강한 무전 효과와 음성 −3dB 처리를 유지합니다. [FAA 교신 지침](https://www.faa.gov/air_traffic/publications/aim_html/chap4_section_2.html)의 호출부호·용건·수신 확인 구성을 참고한 창작 대사이며 실제 군 교신 절차의 재현은 아닙니다.

우선순위는 레이더 락온·포탄 접근 경고 > 관제 교신 > 적 교신입니다. 관제 교신은 적 교신을 끊고, 관제 중 새 적 교신은 버립니다. 관제 볼륨은0.4, 적 교신은0.28입니다. 같은 요청은 한 번만 알리고 관제 중 도착한 다른 요청은 쌓지 않습니다. 첫 실행의 파일 로딩만 최대1초 기다리며, 경고·일시정지·종료·음소거·탭 숨김·요청 완료 때 기다리던 교신을 취소합니다. 새 녹음의 기술적 검증은 수행했으며 발음과 연기를 직접 청취 평가한 것은 아닙니다. [제작 보관본](../samples/enemy-radio/google-tts/control-tower-v2/control-strike-request.wav)과 [대사·파일 기록](control-manifest.json)을 참고하세요.
