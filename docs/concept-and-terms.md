# 폴른 히어로즈 — 콘셉트 리뷰와 용어 기준

2026-09-28 · 현재 로컬 구현 기준

전투 수치와 재생 정책은 [현재 전투 규칙](current-rules.md)을 따른다.

## 핵심 경험

출격 → 시설 폭격과 공중전 → 전사 → 전쟁 기여도 기록 → 다음 출격.

영웅이 살아 돌아오는 것보다, 살아 있는 동안 무엇을 해냈는지가 중요하다. 이 감정은 전투의 결과와 남은 기록으로 전달한다. 시작 화면과 종료 화면에 추모 문장이나 세계관 설명을 반복하지 않는다.

## 용어

| 대상 | 화면 용어 | 적용 기준 |
| --- | --- | --- |
| 게임 이름 | 폴른 히어로즈 / FALLEN HEROES | ‘히어로’는 제목에만 사용 |
| 출격하는 인물 | 영웅 | 기체·계정과 구분 |
| 입력하는 이름 | 이름 | 이름 변경은 같은 플레이어의 기록을 유지 |
| 조종 대상 | 지휘기 | 영웅이 조종하는 기체 |
| 추종 기체와 집단 | 드론 / 편대 | 수량은 ‘기’ |
| 한 번의 플레이·시작 행동 | 출격 | 시작 ‘출격’, 재시작 ‘다음 출격’ |
| 영웅의 죽음 | 전사 | 기체 파괴는 ‘격추’ |
| 성과 점수 | 전쟁 기여도 | 전투·결과는 전체 이름, 순위·합계는 기여도 순위·누적 기여도·최고 기여도 |
| 지상 목표 파괴 | 진지 제압 | 표에서는 ‘제압’, 수량은 ‘곳’ |
| 공중전 성과 | 적 지휘기 격추 | 표에서는 ‘격추’, 수량은 ‘기’; 드론 합류와 구분 |
| 경과 시간 | 출격 시간 | 좁은 표에서는 ‘시간’, 전쟁 기여도에 직접 가산하지 않음 |
| 기록을 보는 곳 | 전장의 영웅들 | ‘기여도 순위’와 ‘내 출격’ 탭 |
| 저장된 한 번의 플레이 | 출격 기록 | 다시 보는 기능은 ‘마지막 출격’. 재생 아이콘과 접근성 이름 ‘마지막 출격 다시 보기’를 함께 사용 |
| 연습 모드 | 훈련 | 기여도 순위·전사 기록에서 제외 |
| 시설 공격 / 강화 장비 | 시설 폭격 / 드론 공격력 | 드론당 1회 공격 피해 10 + 단계당 5, 최대 35; 각 드론이 독립적으로 투하 |
| 성장 자원과 행동 | 회수 부품 / 개량 | 전쟁 기여도와 별도; 출격마다 초기화 |

‘비행’은 실제 이동과 산개 비행 같은 장비명에, ‘작전’은 작전 구역 같은 전장 표현에 사용한다. 한 판이나 점수의 다른 이름으로 쓰지 않는다. 영어 코드 식별자·저장 키·API 경로는 기존 기록과 호환되도록 유지한다. 이전 서버의 ‘출격 재생’·‘리플레이’ 오류도 재전송 처리를 위해 인식한다.

## 드론 증원 규칙

아군은 4기로 시작하며 ‘드론 증원’을 선택할 때 2기가 합류한다. 최대 6단계·편대 16기이며, 가득 찬 편대에는 증원 선택지를 제시하지 않는다. 부품 회수에 따른 아군 자동 증원과 증원의 부품 획득 보너스는 제거했다. 적 드론의 통제권 확보·이탈 드론 회수는 기존 전투 규칙을 따른다. 첫 개량부터 가능한 카드 중 최대 3장을 중복 없이 무작위로 제시한다. 증원 카드에는 실제 기체 수의 전후 변화를 표시한다.

## 드론 공격력 규칙

장비명은 ‘드론 공격력’, 카드의 수치는 ‘드론당 공격력’으로 표시한다. 기본 10에서 단계마다 5씩 올라 최대 35이며 초당 피해량이 아닌 드론 1기의 1회 공격 피해다. 모든 아군 드론과 새로 합류한 드론에 적용한다. 구역 안의 각 드론은 0.88초 간격으로 독립적으로 폭탄을 투하한다. 4기가 모두 한 번씩 공격하면 기본 총피해는 40, 6기면 60이다. 실제 화력에는 구역 진입 여부·재장전·남은 시설 내구도가 영향을 준다.

공격 간격은 기존 4기 편대의 지속 화력을 기준으로 정했다. 구역 이탈·재진입·목표 변경·소속 변경으로 재장전을 초기화하지 않는다. 비행 중인 폭탄의 피해량은 투하 시점에 고정한다. ‘시설 피해’는 목표에 누적된 피해이며 드론의 공격력과 구분한다. 현재 규칙 15의 마지막 출격만 재생하며, 과거 전투 규칙 분기는 제거했다. 옛 점수와 영웅의 이름은 유지한다.

## 전체 리뷰

### 1. 전쟁 기여도의 의미가 전장에서 보여야 한다 — 다음 설계의 우선순위

현재 진지를 제압하면 표적이 파괴되고 포대의 남은 사격이 취소되며 부품과 전쟁 기여도를 얻는다. 그래서 개별 목표를 없앴다는 반응은 있다. 다만 아군의 전진·구조·전선 변화는 없고, 다음 출격의 전장은 초기화된다. ‘전장에 얼마나 기여했나’의 더 큰 의미는 아직 주로 숫자로 전달된다.

다음 개선은 제압 직후 아군이 그 구역으로 전진하는 등, 실제 행동과 연결된 전장 반응 하나를 만드는 것이 적절하다. 전쟁 기여도 설명이나 추모 문장을 추가하는 것은 이 체감을 대신하지 못한다. 출격 간 전장 상태를 보존하는 캠페인은 별도 설계 선택이며 현재 구현된 기능이 아니다.

### 2. 죽음은 정상적인 끝이지만, 필연성을 보장하는 규칙은 없다

현재 출격에는 제한 시간과 생존 승리가 없다. 난이도는 110초까지 상승하고 적 수에도 상한이 있다. 따라서 ‘전사할 때까지 싸운다’는 구조는 구현되어 있지만, 모든 플레이어가 반드시 전사한다는 보장은 없다.

의도적으로 피할 수 없는 즉사를 추가하면 조작과 판단의 의미가 약해진다. 장기 플레이에서 위험이 정체되는지 먼저 확인하고, 필요하면 회피 가능한 위협과 목표의 위험을 조정한다. 이번 용어 정리에서 난이도나 전투 규칙을 바꾸지는 않았다.

### 3. 기록의 단위는 영웅 개인과 아직 완전히 일치하지 않는다

서버 기여도 순위는 플레이어당 최고 출격 한 건이며, 이름을 바꾸면 순위의 이름도 바뀐다. ‘내 출격’은 당시 이름을 보존한 최근 50건의 전사 기록이다. 같은 이름으로 다시 출격할 수 있고 별도의 영웅 생성·영웅별 생애 모델은 없다.

이 구조에 맞게 재시작은 ‘다음 출격’, 합계는 고유 인원 수를 암시하는 ‘전사자’ 대신 ‘전사’로 표시했다. 모든 전사자를 독립된 인물로 기리는 명부가 필요하다면, 영웅 식별자와 이름을 출격별로 고정하는 변경이 선행되어야 한다.

### 4. 점수 방향은 콘셉트와 맞는다

전쟁 기여도는 진지 제압 1,000점 + 적 지휘기 격추 200점이다. 시설 명중·피해량과 생존 시간에는 점수를 주지 않는다. 위험을 감수하고 전장 목표를 수행하는 방향과 맞는다. 다만 1,000:200의 비중이 실제로 목표 수행을 유도하는지는 사람의 플레이로 확인해야 한다.

동점에서 출격 시간이 순위에 영향을 주는 기존 규칙은 유지한다. 시간을 완전히 평가에서 제외할지는 순위 정책의 별도 결정이다.

## 이번에 반영한 화면 기준

- 시작: 제목·이름·출격, 저장된 기록이 있을 때만 재생 아이콘과 마지막 출격.
- 전투: 전쟁 기여도·출격 시간·진지 제압·드론·회수 부품. 폭격 목표는 수행할 행동을 전달한다.
- 결과: 전사·이름·전쟁 기여도·실제 제압/격추·다음 출격. 원인·시간·장비는 출격 상세에 둔다.
- 전장의 영웅들: 기여도 순위와 내 출격. 순위 표의 점수 이름은 ‘전쟁 기여도’다.
- 마지막 출격: 재생 중에는 ‘재생 중’, 중단 시에는 ‘재생 중단’을 함께 표시한다. 성공 시 개발용 검증 메시지를 노출하지 않는다.
- 도움말: 조작·전투 규칙과 점수 계산을 모은다. 장비 선택에 필요한 효과 설명은 유지한다.

훈련·중도 포기·기록 재생은 새 전사 기록이나 전쟁 기여도를 만들지 않는다. 이 문서는 현재 구현과 제안을 구분하며, 아직 없는 전장 성과를 화면 문구로 주장하지 않는다.
