# 편대전 — 자리싸움과 실시간 편대 순위

2026-09-30

플레이어가 다시 출격하는 이유를 조종과 진로 차단에서 찾는다. 업그레이드 조합 확장은 보류한다. 현재 플레이는 편대전만 제공하며, 폭격 출격과 옛 순위·재생 화면의 진입 경로는 제거한다.

## 교전과 성장

아군 4기로 적 12기 편대에 맞선다. 아군 드론으로 적 지휘기의 비행 경로를 차단해야 한다. 지휘기끼리 부딪히면 양쪽 모두 격추되고 처치 수는 늘지 않는다. 가속은 앞자리를 잡는 수단이고 결집은 감속을 통해 좁게 도는 수단이다.

적 지휘기가 격추되면 남은 드론은 같은 객체와 같은 위치·방향을 유지하면서 회색으로 호버링한다. 속도와 회전, 이전 비행운을 지운다. 화면에서는 드론마다 다른 2.3~2.9초 리듬으로 상하 약 ±3.6, 좌우 약 ±1.5만큼 움직이고 약 5도 기울어진다. 작은 그림자와 희미한 추진광이 높이감을 더하며 합류 진행 원도 기체를 따라간다. 격추 직후 약 0.4초 동안 서서히 움직임을 키운다. 모두 표시 효과일 뿐 실제 위치는 이동하지 않는다. 일시정지에서는 표시 효과도 멈추며, 동작 줄이기 설정에서는 고정된 모습으로 표시한다.

격추한 플레이어에게 자동 지급하지 않는다. 아군이나 다른 적이 가까이 머물러 통제권을 확보하면 소속이 바뀌고 다시 비행한다. 합류 진행 중에도 실제 위치는 고정되며, 멀어지면 진행도가 감소한다. 편대전에서는 아군과 적 모두 드론 수 상한 없이 합류로 성장한다. 거리 판정과 소속 변경 후 충돌 유예는 유지한다. 살아 있는 지휘기와 연결만 끊긴 드론은 기존처럼 비행한다.

## 돌아다니며 모으는 중립 드론

새 판에는 중립 드론 64기를 맵 전체에 한 기씩 흩어 배치한다. 서로 최소 230, 맵 경계에서 120 이상 떨어지며 시작 편대의 실제 기체에서 180 이상 거리를 둔다. 배치 공간이 부족하면 강제로 겹쳐 놓지 않는다. 기존 회색 드론처럼 제자리에서 호버링하고, 지휘기나 편대가 가까이 머무르면 기존 합류 규칙으로 모을 수 있다. 드론을 모두 잃은 지휘기도 다시 한 기부터 모을 수 있다.

중립 드론을 수거하면 4초마다 부족한 수만큼 최대 3기를 보충한다. 보충 위치는 플레이어에서 900 이상, 살아 있는 편대 기체에서 180 이상, 다른 중립 드론에서 220 이상 떨어진 곳이다. 현재 남아 있는 배치 드론만 64기 목표에 집계한다. 격추된 편대의 생존 드론이나 연결이 끊어진 드론을 옮기거나 재활용하지 않는다. 일시정지·게임 종료 중에는 보충하지 않으며 새 판에서 배치와 시간을 초기화한다.

배치된 중립 드론은 적도 확보할 수 있다. 충돌 위험이 없는 이 드론들 때문에 적의 증원이 막히지 않도록 적 출현의 거리 검사에서는 제외한다. 실제 편대 기체와 격추 후 생존 드론, 일반 이탈 드론은 기존 안전거리를 유지한다. 추격 중인 적이 배치 드론마다 방향을 바꾸지 않도록 편대전의 추가 수거 판단을 제한하며, 수거를 선호하는 적의 기존 행동은 유지한다.

## 드리프트 조종 실험

빠른 선회에서는 지휘기가 먼저 꺾이고 드론은 이전 속도를 유지하며 바깥으로 흘러, 뒤늦게 꼬리가 휘둘리게 한다. 지휘기의 이동·회전·가속·에너지·기존 감속과 입력 매핑은 변경하지 않는다. 새로운 급브레이크나 조작 버튼은 추가하지 않는다. 아군과 적의 소속 드론에 같은 처리를 적용하며, 호버링 중인 중립 드론과 옛 모드는 영향을 받지 않는다.

드론은 근처 지휘기의 실제 속도와 회전에서 선회를 감지하고, 멀리 있는 드론은 가까운 앞쪽 드론을 통해 관성 상태를 이어받는다. 약 0.2초에 걸쳐 관성을 키우며 최대 상태에서는 속도 정렬 반응 32%, 선회 반응 38%를 유지한다. 직진·감속 후에는 약 0.5초에 걸쳐 회복한다. 국소 연결 거리의 55~85%에 가까워지면 조종 반응을 되찾아 연결을 유지할 기회를 준다. 실제 거리 판정은 그대로이며, 위치를 옮겨 주거나 강제로 소속을 유지하지 않는다. 다른 드론을 따라잡는 회전이 새로운 드리프트를 끝없이 만들지 않도록 한다.

이 값은 조종 감각을 비교하기 위한 실험 수치다. 긴 무리한 선회에서는 기존 규칙에 따라 드론이 이탈할 수 있다.

## 두 버튼으로 편대 모양 바꾸기

기존 왼쪽 가속과 오른쪽 감속·결집을 사용한다. 빠르게 가는 근처 지휘기나 앞쪽 드론을 보면 뒤따르는 간격을 늘려 꼬리를 길게 만든다. 가속 중 방향을 바꾸면 기존 드리프트와 함께 꼬리가 크게 휘어진다. 브레이크를 밟으면 지휘기가 먼저 감속하고 드론은 잠시 관성을 유지한 뒤 모인다. 다시 가속하면 길게 뻗어 나간다. 새 버튼이나 정해진 콤보, 보호 효과는 없다.

가속을 오래 유지하거나 큰 편대를 급하게 꺾으면 실제 연결 거리를 넘어 이탈할 수 있다. 이것은 전략적 리스크로 남긴다. 브레이크를 일찍 밟아 수습할 여지는 주되, 너무 늦게 감속했을 때 모든 드론의 복귀를 보장하지 않는다. 연결 거리, 충돌, 합류와 지휘기의 조작·에너지 수치는 그대로다.

근처 흐름의 속도와 이미 전달되는 결집 정도로 후류 간격·속도 정렬·감속 반응만 바꾼다. 새 기체 상태나 전역 입력 전달은 추가하지 않는다. 연결이 벌어지는 속도를 고려해 조종 반응을 회복하지만 실제 이탈 판정은 유지한다. 중립 호버링과 옛 모드는 기존 처리를 따른다.

## 현재 판의 순위와 UI

우측 상단의 **편대 순위**는 살아 있는 지휘기들을 현재 드론 수 내림차순으로 표시한다. 지휘기 자체는 숫자에 넣지 않는다. 회색 드론은 소속이 정해진 뒤에 집계하며 격추된 지휘기는 목록에서 빠진다. 동률은 고정된 식별자 순으로 정해 화면이 불필요하게 흔들리지 않게 한다. 내 이름과 행은 강조한다.

순위는 이번 전투에만 적용한다. 서버 순위나 점수 제출 기능을 연결하지 않는다. 기존 저장 이름·기록·재생·서버 데이터는 보존한다.

화면의 게임 방법·상시 조작 설명·하단 안내 상자는 제거한다. 드론 수, 가속 에너지, 지도, 실시간 순위와 짧은 전투 알림을 남긴다. 이름 선택, 음량, 일시정지와 재시작은 유지한다. 그래픽 출처 표기는 시작 화면에 둔다.

종료 화면은 작은 중앙 카드에 게임 오버, 최대 드론·격추·생존 시간과 다시 시작 버튼을 표시한다. 시작 화면으로 돌아가기는 작은 보조 버튼으로 둔다. 상세 기록과 긴 설명, 신호 끊김·재연결 연출 없이 즉시 다음 판을 시작할 수 있다.

## 적 배치

첫 적은 12기, 초기 거리는 340~430이며 플레이어 앞을 가로지르는 항로로 시작한다. 12초부터 두 번째 적이 진입할 수 있고 동시 적 편대는 최대 2개다. 격추 후에는 최소 9초 동안 증원을 기다린다. 후속 적은 8~12기이며 기존 지휘기·드론에서 최소 420 떨어진 안전한 위치를 찾지 못하면 나중에 다시 시도한다. 이 수치는 재미를 확인하기 위한 첫 가설이다.

## 구현 범위

편대전은 `src/fleet-battle.mjs`에서 기존 `Game`을 확장한다. 일반 비행의 관성·가속·결집·충돌·연결 규칙을 재사용하며, 격추된 편대의 생존 드론과 맵에 배치한 중립 드론에 호버링 상태를 부여한다. 시설 폭격·대공포·개량 선택·제한 시간은 활성화하지 않는다. 옛 엔진과 저장 모듈은 호환성 확인을 위해 남기지만 현재 앱은 편대전만 시작한다.

옛 업그레이드 모드의 16기 상한을 편대전이 그대로 물려받아, 수가 찬 뒤 회색 드론이 합류하지 않는 문제가 있었다. 편대전에서만 `flockLimit`을 무제한으로 바꾸며, 다른 모드로 전환하면 기존 상한으로 돌아간다. 이는 합류 조건의 수 제한만 제거하는 변경이며, 자동 지급이나 초기 편대 증원은 아니다.

## 사람 플레이에서 확인할 점

- 적의 지휘기와 비행 방향, 피해야 할 드론이 분명하게 읽히는가?
- 가속과 감속 선회로 실제 차단 기회를 만들 수 있는가?
- 격추와 전사의 원인을 자신의 이동 경로로 설명할 수 있는가?
- 멈춰 있는 드론을 두고 아군과 적이 먼저 확보하려는 자리싸움이 생기는가?
- 편대 크기와 실시간 순위 변화가 다음 교전의 동기가 되는가?

자동 검증은 규칙과 화면 동작을 확인한다. 재미와 난이도는 사람 플레이로 판단한다.

## 검증 결과

전체 자동 테스트 325개 통과, 빌드와 변경 형식 검사 통과. 실제 비행 업데이트에서 4기 편대의 진로 차단으로 12기 편대 지휘기를 격추하는 기존 검증을 유지했다. 호버링 위치·속도·방향·비행운, 합류 중 정지와 이탈 시 진행 감소, 아군·적 회수와 비행 재개, 16기 상한과 접촉 조건, 드론 수 보존, 일시정지·재시작·일반 연결 상실의 비행을 검증했다. 동일 난수·입력으로 기존 폭격 엔진의 재생 지문도 일치한다.

순위 검증은 현재 드론 수 변화, 동률 순서, 사망과 증원, 회색 드론 제외, 원본 편대 배열과 난수 흐름 보존을 포함한다. 브라우저에서는 설명 UI 제거, 초기 4기 대 12기 순위, 사망한 지휘기 제외와 증원 반영, 내 행 강조, 조작·일시정지·종료·재시작을 확인했다. 긴 이름은 숫자를 밀어내지 않고 줄임 표시하며, 새 판에서는 순위와 이전 알림을 초기화한다. 실제 합류로 아군이 16기가 되면서 순위가 1위로 갱신되는 것도 확인했다. 확인 범위에서 콘솔 오류는 없었다.

소스 변경안은 프로젝트의 제한 모드 Claude Opus 5.5 작업자가 작성하고 주 에이전트가 검토·적용·검증했다. 기존 사용자 변경과 저장 데이터는 보존했다. 사람 플레이테스트와 배포, 커밋·푸시는 하지 않았다.

호버링 표시 보강 후에는 편대전 테스트 15개와 빌드·구문·변경 형식 검사를 다시 통과했다. 전체 테스트는 재실행하지 않았다. 실제 렌더러를 사용하는 임시 확대 미리보기에서 드론별 상하·좌우·기울기 변화와 진행 원 정렬을 확인했고, 일시정지 전후의 정지 화면이 일치했다. 게임과 미리보기에서 콘솔 오류는 없었으며 임시 미리보기는 확인 후 종료했다.

종료 화면 간소화 후에는 기존 편대전 UI 테스트 1개, 빌드·구문·변경 형식 검사를 통과했다. 전체 테스트는 재실행하지 않았다. 브라우저에서 실제 종료 시 세 기록과 작은 카드, 다시 시작 버튼의 포커스, 새 판의 초기화와 시작 화면 복귀를 확인했다. 카드 내용 넘침과 콘솔 오류는 없었다.

편대전 수 상한 제거 후 전체 테스트 326개와 빌드·구문·변경 형식 검사를 통과했다. 아군과 적의 실제 비행 중 16기 초과 합류, 64기 편대의 추가 합류, 중복 없는 드론 수 보존, 원격 합류 거부, 옛 모드로 돌아갈 때의 16기 제한과 재생 지문 일치를 검증한다. 새 성장 회귀 검증 3개는 수정 전 소스에서 모두 실패하고 수정 후 통과했다. 별도 60초 비행 시뮬레이션에서는 회색 드론 4기를 전부 회수하며 16→20, 64→68, 128→132기가 되었고 마지막까지 유지했다.

현재 개발 기기의 Node 시뮬레이션 측정에서 편대 3개에 각각 16/64/128/256기와 같은 수의 호버링 드론을 둔 장면의 업데이트 평균은 각각 0.22/1.05/2.77/7.00ms, 95백분위는 0.30/1.17/2.99/7.90ms였다. 매 스텝 전 배치를 복원해 동일한 밀도와 드론 수를 유지하고, 준비 120회 뒤 360회를 측정했다. 측정에는 화면 그리기와 브라우저 부하가 포함되지 않으므로 전체 프레임 속도를 보장하는 값은 아니다.
